测试序列可以按类别准备：

| 检查目标       | 输入     | 预期逐字符输出 |
| -------------- | -------- | -------------- |
| 最短匹配       | `baa`    | `001`          |
| 两个 b         | `bbac`   | `0001`         |
| 多个 b         | `bbbcc`  | `00001`        |
| 连续匹配       | `bacbac` | `001001`       |
| 匹配后继续输入 | `bacac`  | `00100`        |
| 其他字符打断   | `bxaac`  | `00000`        |
| 不完整匹配     | `abax`   | `0000`         |
