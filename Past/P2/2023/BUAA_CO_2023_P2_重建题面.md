## T1.合并两个有序数组

**任务** 
使用 MIPS 汇编语言编写程序。给你两个按**非递减顺序**排列的整数数组 `nums1` 和 `nums2`，请将两个数组合并为一个数组 `nums`，使合并后的 `nums` 同样按非递减顺序排列。

- 数组中可能有重复元素，合并时两个数组中的所有元素都要保留。
- 数组元素可能为负数。

**输入格式**

1. 第 1 行输入一个整数 $n_1$，为 `nums1` 的元素个数。
2. 接下来 $n_1$ 行，每行输入一个整数，依次为 `nums1[i]`。
3. 下一行输入一个整数 $n_2$，为 `nums2` 的元素个数。
4. 接下来 $n_2$ 行，每行输入一个整数，依次为 `nums2[i]`。

**约束条件**

- $-128 \le nums1[i] \le 128$
- $-128 \le nums2[i] \le 128$
- $1 \le n_1 \le 64$
- $1 \le n_2 \le 64$
- 保证 `nums1` 与 `nums2` 均已按非递减顺序排列

**输出格式**

- 依次输出合并后的 `nums[i]`，每两个元素之间用一个空格分隔，最后一个元素之后可以有一个空格。

## T2.Asteroids

**任务** 
使用 MIPS 汇编语言翻译下面给出的 C 语言代码。

给定一个整数数组 `asteroids`，表示同一行上的一列行星。对于数组中的每个元素，其绝对值表示行星的大小，正负表示行星的移动方向（正表示向右移动，负表示向左移动）。每一颗行星以相同的速度移动。

找出碰撞后剩下的所有行星，剩余行星保持原来的相对顺序。碰撞规则如下：

1. 两颗行星相互碰撞，较小的行星会爆炸；
2. 如果两颗行星大小相同，则两颗行星都会爆炸；
3. 两颗移动方向相同的行星，永远不会发生碰撞。

**输入格式**

1. 第 1 行输入一个整数 $n$，为数组 `asteroids` 的元素个数。
2. 接下来 $n$ 行，每行输入一个整数，依次为 `asteroids[i]`。

**约束条件**

- $-128 \le asteroids[i] \le 128$
- $asteroids[i] \ne 0$
- $1 \le n \le 64$

**输出格式**

1. 第一行输出碰撞后剩余行星的数量 `num`。
2. 第二行按顺序输出剩余行星的值，元素之间用一个空格分隔。
3. 即使 `num` 为 0，第一行之后仍要输出换行。

**C语言代码**

```c
#include <stdio.h>

int st[64];
int asteroids[64];
int returnSize;
int asteroidsSize;

int main() {
    scanf("%d", &asteroidsSize);
    for (int i = 0; i < asteroidsSize; i++) {
        scanf("%d", &asteroids[i]);
    }

    int pos = 0;
    for (int i = 0; i < asteroidsSize; i++) {
        int alive = 1;
        while (alive && asteroids[i] < 0 && pos > 0 && st[pos - 1] > 0) {
            alive = st[pos - 1] < -asteroids[i];
            if (st[pos - 1] <= -asteroids[i]) {
                pos--;
            }
        }
        if (alive) {
            st[pos++] = asteroids[i];
        }
    }

    returnSize = pos;
    printf("%d\n", returnSize);
    for (int i = 0; i < returnSize; i++) {
        printf("%d ", st[i]);
    }
    return 0;
}
```

## T3.删除数字

**任务**  
使用 MIPS 汇编语言编写程序。给定一个整数 $n$，初始序列为 $[1, 2, 3, \dots, n]$。对序列反复执行以下操作，直到序列中只剩下一个数字：

1. **从左向右**：删除当前序列的第一个数字，然后从左向右每隔一个数字删除一个数字，直到到达序列末尾；
2. **从右向左**：删除当前序列的最后一个数字，然后从右向左每隔一个数字删除一个数字，直到到达序列开头；
3. 两个方向交替进行。

输出最后剩下的数字。

**输入格式**

- 输入一个整数 $n$。

**约束条件**

- $n \ge 1$

**输出格式**

- 输出一个整数，为最后剩下的数字。
