# 题目要求

实现以下指令：

```asm
slt $rd, $rs, $rt
```

功能定义：

- 如果寄存器 `$rs` 中的有符号整数小于 `$rt` 中的有符号整数，则令 `$rd = 1`。
- 否则令 `$rd = 0`。
- 其他寄存器不受影响。

| 字段   |  位宽 | 二进制值       |
| ------ | ----: | -------------- |
| opcode | 6 bit | `000000`       |
| rs     | 5 bit | 源寄存器编号   |
| rt     | 5 bit | 源寄存器编号   |
| rd     | 5 bit | 目标寄存器编号 |
| shamt  | 5 bit | `00000`        |
| funct  | 6 bit | `101010`       |

实现步骤：

1. 在 Controller 中识别 `slt` 
2. 让 ALU 能完成符号大小比较
3. 让 ALU 能在result里面输出最后的值

# 题目要求

在现有 Logisim CPU 中新增一条 MIPS 指令：`j`。

## 指令格式（J 型）

| 字段   | 位宽   | Opcode       |
| ------ | ------ | ------------ |
| opcode | 6 bit  | `000010`     |
| target | 26 bit | 跳转目标字段 |

## 功能定义

执行 `j target` 时，无条件跳转到目标地址：

\[ PC=\{(PC+4)[31:28],\ target[25:0],\ 2'b00\} \]

# 题目要求

在现有 Logisim CPU 中新增一条 MIPS 指令：`and`。

## 指令格式（R 型）

| 字段   | 位宽  | 说明           |
| ------ | ----- | -------------- |
| opcode | 6 bit | `000000`       |
| rs     | 5 bit | 第一个源寄存器 |
| rt     | 5 bit | 第二个源寄存器 |
| rd     | 5 bit | 目标寄存器     |
| shamt  | 5 bit | `00000`        |
| funct  | 6 bit | `100100`       |

## 功能定义

```asm
and rd, rs, rt
```

\[ R[rd]=R[rs]\ \&\ R[rt] \]

# 题目要求

指令格式：J 型

| 字段   | 位宽   | 值           |
| ------ | ------ | ------------ |
| opcode | 6 bit  | `000011`     |
| target | 26 bit | 跳转目标地址 |

## 功能定义

```asm
jal target
```

执行时：

1. 将 `PC + 4` 写入寄存器 `$31`（即 `$ra`）。
2. 无条件跳转到目标地址。
