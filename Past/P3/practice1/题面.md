# 题目要求

实现以下指令：

```asm
slt $rd, $rs, $rt
```

功能定义：

- 如果寄存器 `$rs` 中的有符号整数小于 `$rt` 中的有符号整数，则令 `$rd = 1`。
- 否则令 `$rd = 0`。
- 其他寄存器不受影响。

| 字段   |  位宽 | 二进制值       |
| ------ | ----: | -------------- |
| opcode | 6 bit | `000000`       |
| rs     | 5 bit | 源寄存器编号   |
| rt     | 5 bit | 源寄存器编号   |
| rd     | 5 bit | 目标寄存器编号 |
| shamt  | 5 bit | `00000`        |
| funct  | 6 bit | `101010`       |

实现步骤：

1. 在 Controller 中识别 `slt` 
2. 让 ALU 能完成符号大小比较
3. 让 ALU 能在result里面输出最后的值
