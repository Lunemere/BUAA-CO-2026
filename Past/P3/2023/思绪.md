# BOOEZ

说实话，这道题也并不困难

## Controller

还是识别指令，需要权限：说实话不需要任何权限，但是注意NPC_Sel需要选择新的

## ALU

需要计算GRF输出值的1和0的数量，然后再看看余数和0和1的关系，然后输出NPC具体的值就是可以了

## NPC

这里还是可以直接新加一条NPC的分路，这样最简单了

## Test

### 测试一

```asm
ori $t0, $0, 102
lui $t1, 0x7
ori $t1, $0, 0x4201
booez $t0, $t1, label
```

不过貌似我们做的CPU，并不能支持这种高低位的方式，虽然原版也不支持（）

### 测试二

```asm
ori $t0, $0, 100
ori $t1, $0, 0x4201
booez $t0, $t1, label
```

# CSWS

## Controller

继续加入识别即可，权限：符号扩展，立即数输入，写入内存

## ALU

这里可以直接输出要写入的地址就可以了，不过值得注意的是，再加一个新的相等的判断

## DM

在这里写入数据的前侧再加入一个MUX来筛选数据

## Test

### 测试一

```asm
lui $t0, 0x8134
ori $t1, $0, 123
csws $t1, 0x23($t0)
```

### 测试二

```asm
lui $t0, 0x7134
ori $t1, $0, 123
csws $t1, 0x23($t0)
```
