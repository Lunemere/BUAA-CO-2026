# BUAA CO 2023 P1 重建题面

## T1 二进制向量点积

### 题目描述

使用 Verilog HDL 设计组合逻辑电路，计算两个 32 维二进制向量的点积。

输入向量的每一位分别表示一个取值为 `0` 或 `1` 的分量。将两个向量对应位置的分量相乘，再对 32 个乘积求整数和，输出结果。

$$
result=\sum_{i=0}^{31} vector\_a[i]\times vector\_b[i]
$$

每个乘积只可能为 `0` 或 `1`，最终结果的取值范围为 $0\le result\le 32$。

### 模块接口

模块名为 `dotProduct`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `vector_a` | 输入 | 32 | 第一个二进制向量 |
| `vector_b` | 输入 | 32 | 第二个二进制向量 |
| `result` | 输出 | 6 | 两向量的点积，无符号整数 |

电路没有时钟和复位信号，输出随输入变化。

## T2 颜色序列检查

### 题目描述

使用 Verilog HDL 设计时序电路，逐个接收颜色，检查颜色序列是否满足排列要求。

输入颜色编码如下。保证输入只取表中三种编码，不出现 `2'b11`。

| `color` | 颜色 |
| --- | --- |
| `2'b00` | 红色 |
| `2'b01` | 绿色 |
| `2'b10` | 蓝色 |

已接纳的颜色序列必须满足以下两条规则。

1. 红色和绿色不能相邻，无论红色 在前还是绿色在前。
2. 同一种颜色不能连续出现三次或更多次。

对于每次输入，判断把本次颜色追加到已经接纳的序列末尾后是否违反规则。合法时接纳该颜色，输出 `check=0`；非法时输出 `check=1`，丢弃本次颜色，原有序列保持不变。

后续输入继续接在已接纳序列后判断，被丢弃的颜色不参与相邻关系和连续次数的计算。

### 模块接口

模块名为 `coloring`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `rst_n` | 输入 | 1 | 低电平有效的异步复位信号 |
| `color` | 输入 | 2 | 本次输入的颜色 |
| `check` | 输出 | 1 | 本次颜色是否被判为非法 |

### 时序与复位要求

- `rst_n=0` 时立即清空已接纳序列，并令 `check=0`。
- `rst_n=1` 时，在每个时钟上升沿接收一次 `color`，并在上升沿之后更新序列和 `check`。
- 空序列可以接纳任意一种合法颜色。
- `check` 只反映最近一次输入的判定结果，不记录历史是否出现过错误。非法输入之后，下一次输入合法时，`check` 恢复为 `0`。
- 两个上升沿之间，输入变化不直接改变已接纳序列或输出。复位优先于颜色接收。

## T3 数字嵌套匹配

### 题目描述

使用 Verilog HDL 设计时序电路，串行接收数字序列，检查其中的数字匹配是否满足嵌套规则

一个数字匹配块以某个数字开始，并以相同数字结束。这两个相同数字之间可以为空，也可以包含若干个完整的下一层数字匹配块。匹配块之间不能交叉

数字匹配规则如下

1. 输入数字的取值范围为 `1` 至 `5`，输入为数字的二进制编码。
2. 最外层匹配块的开始和结束数字必须为 `1`。一个完整序列可以包含若干个首尾相接的最外层匹配块。
3. 如果当前匹配块的外层数字为 $k$，则其内部每个直接嵌套匹配块的外层数字必须为 $k+1$。不能跳过中间数字，也不能在未结束的匹配块内部开始相同或更小数字的匹配块。
4. 外层数字为 `5` 的匹配块内部只能为空，不能继续嵌套
5. 输入过程中允许存在尚未闭合的匹配块。只要已接收的序列仍可能通过继续追加数字形成完整合法序列，就不报错

每次输入一个数字，判断它能否继续当前合法序列。如果可以，则接纳该数字并输出 `check=0`；如果不能，则输出 `check=1`，清空当前序列，同时丢弃引起错误的本次数字。下一次输入从空序列重新开始检查

### 模块接口

模块名为 `numberNest`

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `rst_n` | 输入 | 1 | 低电平有效的异步复位信号 |
| `in` | 输入 | 3 | 本次输入的数字，保证取值为 `1` 至 `5` |
| `check` | 输出 | 1 | 本次数字是否使当前序列违反匹配规则 |

### 时序与复位要求

- `rst_n=0` 时立即清空匹配历史，并令 `check=0`
- `rst_n=1` 时，在每个时钟上升沿接收一个数字，并在上升沿之后更新匹配历史和 `check`。
- 未闭合但仍可合法续写的前缀、已经完成的合法匹配块以及空序列均不报错
- `check` 只反映最近一次输入是否非法；错误后的下一次输入重新判断，合法时恢复为 `0`。
- 两个上升沿之间，输入变化不直接改变匹配历史或输出。复位优先于数字接收
