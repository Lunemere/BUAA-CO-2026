# BUAA CO 2021 P1 重建题面

## T1 奇偶校验

### 题目描述

使用 Verilog HDL 设计组合逻辑电路，对一个 32 位二进制数据进行奇偶校验编码。数据的最高位为校验位，其余 31 位为有效数据。

根据 `funct` 的值调整最高位，使输出数据中所有 32 位的 `1` 的总数满足指定的奇偶性。

- `funct=0`：进行偶校验，输出中 `1` 的总数为偶数。
- `funct=1`：进行奇校验，输出中 `1` 的总数为奇数。
- `result[30:0]` 必须与 `data[30:0]` 相同。
- `data[31]` 可以被改写；如果原数据已经满足要求，输出与原数据相同。

### 模块接口

模块名为 `parity`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `data` | 输入 | 32 | 待编码的二进制数据 |
| `funct` | 输入 | 1 | 奇偶校验选择信号 |
| `result` | 输出 | 32 | 完成奇偶校验编码的数据 |

电路没有时钟和复位信号，输出随输入变化。

## T2 心情电路

### 题目描述

使用 Verilog HDL 设计一个心情状态机。电路在每个时钟上升沿接收一个事件，根据当前心情、输入事件及在当前心情中停留的时间更新状态。

心情状态及输出编码如下。

| 心情 | 编码 | 含义 |
| --- | --- | --- |
| `ASLEEP` | `3'b000` | 睡觉 |
| `BUSY` | `3'b001` | 忙碌 |
| `SAD` | `3'b010` | 忧虑 |
| `CLUELESS` | `3'b011` | 茫然 |
| `HAPPY` | `3'b100` | 开心 |

输入事件编码如下。

| 事件 | `sign` | 含义 |
| --- | --- | --- |
| `ALARM` | `2'b00` | 闹钟响 |
| `IDEA` | `2'b01` | 有灵感 |
| `FAIL` | `2'b10` | 失败 |
| `SUCCESS` | `2'b11` | 成功 |

### 模块接口

模块名为 `mood`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `reset` | 输入 | 1 | 高电平有效的异步复位信号 |
| `sign` | 输入 | 2 | 当前输入事件 |
| `status` | 输出 | 3 | 当前心情状态的编码 |

### 状态转移要求

1. `ASLEEP` 状态下收到 `ALARM`，转入 `BUSY`；收到其他事件时保持 `ASLEEP`。
2. `BUSY` 状态下收到 `FAIL`，转入 `SAD`；收到 `SUCCESS`，转入 `HAPPY`。若没有发生上述转移，连续保持 `BUSY` 满 3 个完整时钟周期后转入 `ASLEEP`。
3. `SAD` 状态下忽略输入事件，连续保持 `SAD` 满 2 个完整时钟周期后转入 `CLUELESS`。
4. `CLUELESS` 状态下收到 `IDEA`，转入 `BUSY`。若没有发生该转移，连续保持 `CLUELESS` 满 3 个完整时钟周期后转入 `ASLEEP`。
5. `HAPPY` 状态下忽略输入事件，始终保持 `HAPPY`，直到复位。

### 时序与输出要求

- `reset=1` 时立即进入 `ASLEEP`，清除所有停留时间记录。复位优先于其他行为。
- `reset=0` 时，在每个时钟上升沿采样 `sign` 并更新状态。`status` 表示更新后的当前状态，两个上升沿之间不会因 `sign` 改变而变化。
- 每次进入 `BUSY`、`SAD` 或 `CLUELESS` 时，都从进入该状态的时刻重新计时；不继承先前停留时间。
- 若在上升沿 `E0` 进入 `BUSY` 或 `CLUELESS`，且没有触发事件转移，则在后续 `E1`、`E2` 保持该状态，在 `E3` 转入 `ASLEEP`。若在 `E0` 进入 `SAD`，则在 `E1` 保持，在 `E2` 转入 `CLUELESS`。
- `BUSY` 或 `CLUELESS` 在计时到期的同一上升沿收到能触发状态转移的事件时，事件转移优先于计时转移。
- 不引起状态转移的事件不会重新开始计时。

## T3 方程字符串匹配

### 题目描述

使用 Verilog HDL 设计时序电路，逐字符接收 ASCII 字符流，判断从本次复位开始已经接收的整个字符串是否构成一个合法方程。

合法方程由左表达式、一个等号 `=` 和右表达式组成。左右表达式均不能为空，表达式的规则如下。

1. 一个数字字符 `0` 至 `9`，或一个英文字母 `a` 至 `z`、`A` 至 `Z`，构成一个操作数。
2. 表达式由一个或多个操作数组成，相邻两个操作数之间必须且只能出现一个运算符。运算符为 `+`、`-`、`*`、`/` 中的一种。
3. 每个操作数只包含一个字符。不接受多位整数、多字母标识符、括号或一元正负号。
4. 方程中必须且只能出现一个等号。等号两侧都必须是完整表达式。
5. 任意两个非空格字符之间允许插入任意多个空格，开头和末尾也允许有空格。空格仅指 ASCII 编码为 `8'h20` 的字符。
6. 除上述字符外，其他字符均不合法。只检查字符排列是否符合规则，不计算表达式的值。

### 模块接口

模块名为 `equation`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `reset` | 输入 | 1 | 高电平有效的异步复位信号 |
| `in` | 输入 | 8 | 当前输入字符的 ASCII 编码 |
| `out` | 输出 | 1 | 已接收的整个字符串是否构成合法方程 |

### 时序与输出要求

- `reset=1` 时立即清空输入历史，`out=0`。
- `reset=0` 时，在每个时钟上升沿接收一个 `in` 字符。上升沿之后，`out` 表示包含本次字符在内的整个已接收字符串的判断结果。
- 若已接收字符串构成完整合法方程，则 `out=1`；若仍缺少字符，例如尚未出现等号、等号后没有操作数或末尾为运算符，则 `out=0`。
- 已形成合法方程后，继续输入空格时仍输出 `1`。继续输入合法的运算符时输出 `0`，随后输入操作数使右表达式完整时恢复输出 `1`。
- 若某次输入违反排列规则，使已接收字符串无法通过继续追加字符成为合法方程，则进入错误状态。错误状态下始终输出 `0`，后续字符不会重新开始匹配。
- 开始识别一个新的方程前必须复位。复位优先于字符接收。
