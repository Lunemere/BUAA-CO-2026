# BUAA CO 2020 P1 重建题面

## T1 投票器

### 题目描述

使用 Verilog HDL 设计组合逻辑电路，统计加权投票得分。输入的每一位表示一个人是否投票：该位为 `1` 表示投票，为 `0` 表示未投票。例如 `1001` 表示两个人投了票，`00111` 表示三个人投了票。

按以下权重计算总分：

- 普通人 `np`：每票 1 分。
- `vip`：每票 4 分。
- `vvip`：每票 16 分。

总分大于等于 32 时 `res=1`，否则 `res=0`。

### 模块接口

模块名为 `vote`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `np` | 输入 | 32 | 普通人投票情况 |
| `vip` | 输入 | 8 | 8 个 vip 的投票情况 |
| `vvip` | 输入 | 1 | 唯一的 vvip 的投票情况 |
| `res` | 输出 | 1 | 总分是否大于等于 32 |

电路没有时钟和复位信号，输出随输入变化。

## T2 炒菜状态机

### 题目描述

使用 Verilog HDL 设计一个炒菜状态机。电路在每个时钟上升沿采样当前温度 `temp` 和翻面动作 `flip`，更新食物状态。

食物状态及输出编码如下。

| 状态 | `status` | 含义 |
| --- | --- | --- |
| 生 | `2'b00` | 初始状态 |
| 半熟 | `2'b01` | 达到半熟温度，尚未熟透 |
| 熟 | `2'b10` | 已经炒熟 |
| 失败 | `2'b11` | 炒菜失败 |

半熟状态分为两个阶段：尚未翻面的“待翻面”阶段，和已经翻过一次的“已翻面”阶段。两个阶段的 `status` 都是 `2'b01`。

### 模块接口

模块名为 `cook`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `reset` | 输入 | 1 | 高电平有效的异步复位信号 |
| `temp` | 输入 | 8 | 当前温度，按无符号数解释 |
| `flip` | 输入 | 1 | 为 `1` 表示本周期进行一次翻面 |
| `status` | 输出 | 2 | 当前食物状态的编码 |
| `need_flip` | 输出 | 1 | 当前是否需要翻面 |

### 状态转移要求

1. 生：`flip=1` 时转入失败。`flip=0` 时，若 `temp < 120` 保持生；若 `120 <= temp < 130` 转入半熟待翻面；若 `temp >= 130` 转入失败。
2. 半熟待翻面：若 `temp >= 150` 转入失败。若 `130 <= temp < 150`，`flip=1` 时转入半熟已翻面，`flip=0` 时保持。若 `temp < 130`，`flip=1` 时转入失败，`flip=0` 时保持。
3. 半熟已翻面：`flip=1` 时转入失败。`flip=0` 时，若 `temp < 150` 保持；若 `150 <= temp < 180` 转入熟；若 `temp >= 180` 转入失败。
4. 熟：`flip=1` 或 `temp >= 180` 时转入失败，否则保持熟。
5. 失败：保持失败，直到复位。

### 时序与输出要求

- 电路初始处于生状态，`status=2'b00`，`need_flip=0`。
- `reset=1` 时立即回到生状态，`status=2'b00`，`need_flip=0`。复位优先于其他行为。
- `reset=0` 时，`status` 和 `need_flip` 只在时钟上升沿更新，两个上升沿之间不会因 `temp` 或 `flip` 改变而变化。
- 上升沿之后，`status` 为更新后状态的编码。
- 上升沿之后，当且仅当更新后的状态为半熟待翻面，且该上升沿采样到的温度满足 `130 <= temp < 150` 时，`need_flip=1`；否则 `need_flip=0`。

## T3 日期合法性检查

### 题目描述

使用 Verilog HDL 设计时序电路，逐字符接收 ASCII 字符流，判断从本次复位开始已经接收的整个字符串是否构成一个合法日期。

合法日期依次由年份、分隔符、月份、分隔符和日期组成，例如 `1926.8.17`、`2000-10-27`、`2012/12/25`。规则如下。

1. 年份为恰好 4 位十进制数字，首位不能为 `0`。
2. 月份为 1～2 位十进制数字，不能有前导零，数值范围为 1～12。
3. 日期为 1～2 位十进制数字，不能有前导零，数值范围为 1～30，不考虑各月份天数的差别。
4. 分隔符为 `.`、`-`、`/` 中的一种，两个分隔符必须相同。
5. 除数字和上述分隔符外，其他字符均不合法。

### 模块接口

模块名为 `date`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `reset` | 输入 | 1 | 高电平有效的异步复位信号 |
| `char` | 输入 | 8 | 当前输入字符的 ASCII 编码 |
| `ans` | 输出 | 1 | 已接收的整个字符串是否构成合法日期 |

### 时序与输出要求

- `reset=1` 时立即清空输入历史，`ans=0`。复位优先于字符接收。
- `reset=0` 时，在每个时钟上升沿接收一个 `char` 字符。上升沿之后，`ans` 表示包含本次字符在内的整个已接收字符串的判断结果。
- 已接收字符串恰好构成合法日期时 `ans=1`；仍缺少字符时 `ans=0`，例如只收到 `2020`、`2020-` 或 `2020-1-`。
- 合法日期后继续输入能延续的数字时按新字符串重新判断，例如 `2020/3/3` 输出 `1`，接着输入 `0` 得到 `2020/3/30`，仍输出 `1`。
- 若某次输入使已接收字符串无法通过继续追加字符成为合法日期，则进入错误状态。错1误状态下始终输出 `0`，后续字符不会重新开始匹配。开始识别新的字符串前必须复位。

## T4 用户名合法性检查

### 题目描述

使用 Verilog HDL 设计时序电路，逐字符接收 ASCII 字符流。当已接收字符串的某个后缀是合法用户名时输出 `1`，否则输出 `0`。

合法用户名满足正则表达式：

```text
[a-zA-Z]+\.[0-9]+
```

即一个或多个英文字母、恰好一个点 `.`、一个或多个十进制数字，依次相连。

### 模块接口

模块名为 `username`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `reset` | 输入 | 1 | 高电平有效的异步复位信号 |
| `char` | 输入 | 8 | 当前输入字符的 ASCII 编码 |
| `ans` | 输出 | 1 | 已接收字符串是否以合法用户名结尾 |

### 时序与输出要求

- `reset=1` 时立即清空输入历史，`ans=0`。复位优先于字符接收。
- `reset=0` 时，在每个时钟上升沿接收一个 `char` 字符。上升沿之后，`ans` 表示包含本次字符在内的已接收字符串是否存在一个合法用户名后缀。
- 判断只看后缀，之前出现的任何字符都不会使电路进入不可恢复的错误状态。例如收到 `1a.2` 后 `ans=1`；接着收到 `b` 后 `ans=0`；再收到 `.3` 后，后缀 `b.3` 合法，`ans=1`。
