# P1 模拟练习题

三道题分别对应 2024 P1 的三种题型：组合逻辑计数、二进制序列判定、字符流识别。

每道题都配有自检测试文件 `tb_*.v`。把你的设计文件和对应的测试文件加入 ISE 工程，运行仿真后在控制台查看结果：全部正确时输出 `PASS`，否则输出 `FAILED` 并打印前 10 个错误（输入、实际输出、期望输出）。参考答案在 `answers/` 中，建议做完再看。

建议流程：先用一句话写出电路需要记住什么，再画出“状态 × 输入类型”表并填满每一格，然后写代码，最后跑测试。

## T1 连续 1 段计数

### 题目描述

使用 Verilog HDL 设计组合逻辑电路，统计 32 位二进制向量 `a` 中极大连续 `1` 段的个数。

一个极大连续 `1` 段是若干个相邻的 `1`，且两端（若存在）都是 `0`。`a[31]` 与 `a[0]` 不相邻，向量不首尾相接。

### 模块接口

模块名为 `run_count`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `a` | 输入 | 32 | 输入向量 |
| `count` | 输出 | 5 | 极大连续 `1` 段的个数，无符号整数 |

### 功能要求

- `count` 的取值范围为 `0` 至 `16`。
- 电路没有时钟和复位信号，输出随输入变化。

### 样例

| `a` | `count` |
| --- | --- |
| `32'b0110_1100_0101_1111_0000_1010_0101_0110` | `9` |
| `32'hFFFF_FFFF` | `1` |
| `32'h0000_0000` | `0` |
| `32'hAAAA_AAAA` | `16` |
| `32'h8000_0001` | `2` |

## T2 段长奇偶判定

### 题目描述

使用 Verilog HDL 设计时序电路，每个时钟上升沿接收一个二进制位，检查自最近一次复位以来的完整输入序列是否合法。

将序列划分为若干个极大的连续相同数字段。序列合法当且仅当满足以下全部条件。

1. 序列非空。
2. 每个只包含 `0` 的段，长度为奇数。
3. 每个只包含 `1` 的段，长度为偶数。

当前尚未结束的最后一段同样参与判定。

### 模块接口

模块名为 `run_check`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `res_n` | 输入 | 1 | 低电平有效的异步复位信号 |
| `number` | 输入 | 1 | 本次输入的二进制位 |
| `check` | 输出 | 1 | 当前完整输入序列是否合法，合法为 `1`，非法为 `0` |

### 时序与复位要求

- `res_n=0` 时立即清空输入历史，并令 `check=0`。
- `res_n=1` 时，在每个时钟上升沿接收一次 `number`，并在上升沿之后更新 `check`。
- 每次输入都追加到序列末尾，`check` 反映当前整个序列的合法性。已经结束的段在复位之前不能删除或重新划分。
- 两个上升沿之间，`number` 的变化不直接改变输出。复位优先于输入接收。
- 序列长度不设上限。

### 样例

依次输入 `1 1 0 0 0 1 1`，每个上升沿之后的 `check` 依次为 `0 1 1 0 1 0 1`。

依次输入 `0 0 1 1`，每个上升沿之后的 `check` 依次为 `1 0 0 0`。读入 `1` 时，第一段 `00` 结束，长度确定为偶数，此后无论输入什么，序列都不合法。（若第三位仍为 `0`，该段长度变为 3，序列重新合法。）

## T3 十六进制列表统计

### 题目描述

使用 Verilog HDL 设计时序电路，每个时钟上升沿接收一个 ASCII 字符，识别字符流中的列表并统计其中合法元素的数量。

列表以 `(` 开始，以 `)` 结束。列表内的候选元素以英文分号 `;` 分隔。合法元素须满足以下要求。

1. 可选的一个符号 `+` 或 `-`，之后紧跟 `0x` 或 `0X`，之后紧跟至少 1 个十六进制数字（`0-9`、`a-f`、`A-F`）。
2. 元素首尾允许有任意数量的 ASCII 空格 `0x20`。符号、`0x`、数字之间以及数字内部都不允许出现空格。
3. 每个候选元素必须整体满足上述要求，不能只计数其中的合法片段。

输出 `cnt` 表示当前列表中已经确认合法的元素数量，输出 `best` 表示所有已经结束的列表中合法元素数量的最大值

### 模块接口

模块名为 `hex_list`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `rst` | 输入 | 1 | 高电平有效的**同步**复位信号 |
| `chr` | 输入 | 8 | 本次输入的 ASCII 字符 |
| `cnt` | 输出 | 8 | 当前列表已确认的合法元素数量，无符号整数 |
| `best` | 输出 | 8 | 已结束列表的合法元素数量最大值，无符号整数 |

### 输入范围

- 每个时钟上升沿输入一个字符，没有输入使能或字符流结束信号。
- 列表外可以出现任意普通字符，但不包含 `(`、`)`、`;`；这些普通字符不参与统计。
- 列表不嵌套，列表内部不会出现额外的 `(`。复位可以发生在列表处理途中
- 每个列表中合法元素的总数不超过 `255`，不考察计数溢出。数字长度不设上限

### 候选元素处理要求

- 读到 `(` 后开始新列表，并令 `cnt=0`。此前的 `best` 保持不变。
- 在列表内读到 `;` 或 `)` 时，结束并判定当前候选元素。在遇到结束分隔符之前，该元素不计入 `cnt`。
- 合法元素计数一次，非法元素不计数。非法元素不影响同一列表中其他元素的判定
- 空元素（只含空格或没有字符）不计数。允许空列表、列表开头或结尾的分号，以及连续分号。

### 时序与复位要求

- `rst=1` 时，在时钟上升沿清空识别历史，并令 `cnt=0`、`best=0`。复位只在上升沿生效，两个上升沿之间 `rst` 的变化不直接改变输出。
- `rst=0` 时，在每个时钟上升沿接收一次 `chr`，并在上升沿之后更新状态和输出。
- 在列表内读到 `;` 时，若刚结束的元素合法，则 `cnt` 加一；否则 `cnt` 保持不变。`best` 保持不变。
- 在列表内读到 `)` 时，先结算最后一个元素。设结算后的本列表合法元素总数为 `C`，则更新 `best` 为原 `best` 与 `C` 中的较大值，同时令 `cnt=0`，结束当前列表。
- 列表尚未结束时不更新 `best`；列表外 `cnt=0`。
- 两个上升沿之间，`chr` 的变化不直接改变识别历史或输出。复位优先于字符接收。

### 样例

每行均从复位开始，表中为最后一个字符之后的输出。

| 输入 | `cnt` | `best` | 说明 |
| --- | --- | --- | --- |
| `(0x1F; -0xab ;+0X0)` | `0` | `3` | 读完第一个 `;` 后 `cnt=1`，第二个 `;` 后 `cnt=2` |
| `( 0x; 12; 0xg1 ;0x 1)` | `0` | `0` | 四个元素都不合法 |
| `abc(;;0x9;)x` | `0` | `1` | 空元素不计数 |
| `(+ 0x1; 0x1 2)` | `0` | `0` | 符号后有空格；数字内部有空格 |
| `()` | `0` | `0` | 空列表 |
