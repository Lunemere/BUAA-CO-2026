# P1 模拟练习题（第二组）

四道题各考一种不同的能力：有符号运算与溢出（组合逻辑）、带数据通路的字符流处理、带计时的控制状态机、寄存器数组。

每道题配有自检测试文件 `tb_*.v`：把你的设计和对应的测试文件加入 ISE 工程，运行仿真后看控制台，全部正确输出 `PASS`，否则输出 `FAILED` 并打印前 10 个错误。参考答案在 `answers/` 中。

## T1 有符号饱和加减法

### 题目描述

使用 Verilog HDL 设计组合逻辑电路，对两个 8 位二进制补码有符号数做加法或减法，结果超出 8 位有符号数范围时饱和到边界值。

### 模块接口

模块名为 `sat_alu`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `a` | 输入 | 8 | 第一个操作数，二进制补码有符号数 |
| `b` | 输入 | 8 | 第二个操作数，二进制补码有符号数 |
| `op` | 输入 | 1 | `0` 表示 `a+b`，`1` 表示 `a-b` |
| `y` | 输出 | 8 | 饱和后的结果，二进制补码有符号数 |
| `of` | 输出 | 1 | 精确结果超出范围时为 `1`，否则为 `0` |

### 功能要求

- 设精确结果（不限位宽）为 `R`。若 `-128 <= R <= 127`，则 `y=R`、`of=0`。
- 若 `R > 127`，则 `y=127`、`of=1`；若 `R < -128`，则 `y=-128`、`of=1`。
- 电路没有时钟和复位信号，输出随输入变化。

### 样例

| `a` | `b` | `op` | `y` | `of` |
| --- | --- | --- | --- | --- |
| `100` | `50` | `0` | `127` | `1` |
| `-100` | `50` | `1` | `-128` | `1` |
| `100` | `-100` | `0` | `0` | `0` |
| `0` | `-128` | `1` | `127` | `1` |
| `-128` | `-128` | `1` | `0` | `0` |

## T2 字符流计算器

### 题目描述

使用 Verilog HDL 设计时序电路，每个时钟上升沿接收一个 ASCII 字符，计算形如 `12+30-5=` 的加减法表达式。

从复位或上一个 `=` 之后开始，到下一个 `=` 为止（含 `=`）的字符构成一个表达式。合法表达式的格式为：

```
数 运算符 数 运算符 ... 数 =
```

1. 数由至少 1 个十进制数字 `0-9` 组成，允许前导零，长度不设上限。
2. 运算符为 `+` 或 `-`，只能出现在两个数之间。
3. 表达式中不允许出现数字、`+`、`-`、`=` 以外的任何字符（包括空格）。

例如 `+5=`、`3++4=`、`4-=`、`=`、`1 2=` 都不合法。

### 模块接口

模块名为 `calc`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `rst` | 输入 | 1 | 高电平有效的异步复位信号 |
| `chr` | 输入 | 8 | 本次输入的 ASCII 字符 |
| `result` | 输出 | 16 | 最近一个合法表达式的值 |
| `error` | 输出 | 1 | 最近结束的表达式是否非法，非法为 `1` |

### 功能要求

- 表达式从左到右计算。结果按 16 位二进制回绕，即对 `65536` 取模；结果为负时按 16 位补码表示。超过 `65535` 的数同样按取模处理。
- 在读入 `=` 的上升沿之后：若该表达式合法，令 `result` 为其值、`error=0`；若非法，`result` 保持不变、`error=1`。
- 其他时刻 `result` 和 `error` 保持不变。读入 `=` 后立即开始下一个表达式。

### 时序与复位要求

- `rst=1` 时立即令 `result=0`、`error=0`，并丢弃尚未结束的表达式。
- `rst=0` 时，在每个时钟上升沿接收一次 `chr`，并在上升沿之后更新状态和输出。
- 两个上升沿之间，`chr` 的变化不直接改变输出。复位优先于字符接收。

### 样例

从复位开始依次输入 `12+30-5=7-10=+5=007=3++4=`：

| 读完 | `result` | `error` |
| --- | --- | --- |
| `12+30-5=` | `37` | `0` |
| `7-10=` | `65533`（即 `16'hFFFD`，表示 -3） | `0` |
| `+5=` | `65533`（保持） | `1` |
| `007=` | `7` | `0` |
| `3++4=` | `7`（保持） | `1` |

另：`65535+2=` 的结果为 `1`。

## T3 带锁定的密码锁

### 题目描述

使用 Verilog HDL 设计时序电路，实现一个 4 位数字密码锁，密码固定为 `2 0 2 4`。连续输错 3 次后锁定 10 个时钟周期。

### 模块接口

模块名为 `lock`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `rst` | 输入 | 1 | 高电平有效的异步复位信号 |
| `key_valid` | 输入 | 1 | 本周期有按键输入 |
| `key` | 输入 | 4 | 按下的数字，`key_valid=1` 时保证为 `0` 至 `9` |
| `open` | 输出 | 1 | 锁已打开 |
| `locked` | 输出 | 1 | 处于锁定状态 |

### 功能要求

- 未锁定时，`key_valid=1` 的上升沿接收一个数字。每 4 个数字构成一次尝试，在接收第 4 个数字的上升沿判定。`key_valid=0` 的周期不接收数字，已输入的部分数字保留。
- 尝试正确：令 `open=1`，错误次数清零。
- 尝试错误：错误次数加一。若错误次数达到 3，则错误次数清零并进入锁定。
- `open=1` 一直保持，直到下一个被接收的数字（它同时是下一次尝试的第一个数字）的上升沿变为 `0`
- 进入锁定的上升沿之后 `locked=1`。此后的 10 个上升沿内忽略所有输入；第 10 个上升沿之后 `locked=0`，从下一个上升沿开始恢复接收数字（新的尝试从第一个数字开始）。

### 时序与复位要求

- `rst=1` 时立即令 `open=0`、`locked=0`，清空已输入的数字和错误次数。
- 所有输出在上升沿之后更新，两个上升沿之间输入的变化不直接改变输出。复位优先。

### 样例

- 从复位开始依次输入 `2 0 2 4`：前三个数字后 `open=0`，第四个数字后 `open=1`。再输入 `5`，`open` 变回 `0`，`5` 是新尝试的第一个数字。
- 从复位开始连续输入 12 个 `1`（三次错误尝试）：第 12 个数字后 `locked=1`。接下来的 10 个周期内，即使输入 `2 0 2 4` 也被忽略；第 10 个周期后 `locked=0`。

## T4 硬件栈

### 题目描述

使用 Verilog HDL 设计一个深度为 8、数据宽度为 8 位的栈（后进先出）

### 模块接口

模块名为 `stack`

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `rst` | 输入 | 1 | 高电平有效的异步复位信号 |
| `push` | 输入 | 1 | 压栈 |
| `pop` | 输入 | 1 | 出栈 |
| `din` | 输入 | 8 | 压栈的数据 |
| `top` | 输出 | 8 | 栈顶元素；栈为空时为 `0` |
| `count` | 输出 | 4 | 栈中元素个数，`0` 至 `8` |
| `err` | 输出 | 1 | 最近一次操作是否失败 |

### 功能要求

每个上升沿根据 `push` 和 `pop` 执行一次操作：

| `push` | `pop` | 操作 |
| --- | --- | --- |
| `0` | `0` | 无操作，栈和 `err` 均保持不变 |
| `1` | `0` | 栈未满：`din` 压栈，`err=0`；栈已满：栈不变，`err=1` |
| `0` | `1` | 栈非空：弹出栈顶，`err=0`；栈为空：栈不变，`err=1` |
| `1` | `1` | 栈非空：用 `din` 替换栈顶元素（个数不变），`err=0`；栈为空：栈不变，`err=1` |

### 时序与复位要求

- `rst=1` 时立即清空栈，令 `count=0`、`top=0`、`err=0`
- 所有输出在上升沿之后更新，两个上升沿之间输入的变化不直接改变输出。复位优先

### 样例

从复位开始依次执行 `push 5`、`push 7`、`pop`、`pop`、`pop`，每个上升沿之后的 (`top`, `count`, `err`) 依次为：

`(5, 1, 0)`、`(7, 2, 0)`、`(5, 1, 0)`、`(0, 0, 0)`、`(0, 0, 1)`
