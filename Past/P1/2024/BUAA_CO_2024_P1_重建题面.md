# BUAA CO 2024 P1 重建题面

## T1 反向逐位比较

### 题目描述

使用 Verilog HDL 设计组合逻辑电路，统计两个 32 位二进制向量反向配对后不同的位数。

输入为 `a[31:0]` 和 `b[31:0]`。按照 `a` 从最高位到最低位、`b` 从最低位到最高位的顺序配对，比较 `a[31-i]` 与 `b[i]`，其中 `0 <= i <= 31`。每一对不同的二进制位计数一次，最终将 32 对的计数结果输出到 `count`。

### 模块接口

模块名为 `different`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `a` | 输入 | 32 | 第一个二进制向量 |
| `b` | 输入 | 32 | 第二个二进制向量 |
| `count` | 输出 | 6 | 反向配对后不同的位数，无符号整数 |

### 功能要求

- 比较对象为二进制位，输入不作有符号数解释。
- `count` 的取值范围为 `0` 至 `32`。
- 电路没有时钟和复位信号，输出随输入变化。

## T2 奇偶交替二进制序列

### 题目描述

使用 Verilog HDL 设计时序电路，每个时钟上升沿接收一个二进制位，检查自最近一次复位以来的完整输入序列是否满足奇偶交替要求。

将序列划分为若干个极大的连续相同数字段。每一段只包含 `0` 或只包含 `1`，相邻段的数字不同。

序列合法当且仅当满足以下两条规则。

1. 序列同时包含 `0` 和 `1`，即至少有两个连续段。
2. 任意两个相邻连续段的长度奇偶性不同。

第一段的长度可以为奇数，也可以为偶数。当前尚未结束的最后一段同样参与判定。

### 模块接口

模块名为 `alternate`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `res_n` | 输入 | 1 | 低电平有效的异步复位信号 |
| `number` | 输入 | 1 | 本次输入的二进制位 |
| `check` | 输出 | 1 | 当前完整输入序列是否合法，合法为 `1`，非法为 `0` |

### 时序与复位要求

- `res_n=0` 时立即清空输入历史，并令 `check=0`。
- `res_n=1` 时，在每个时钟上升沿接收一次 `number`，并在上升沿之后更新 `check`。
- 空序列、只包含 `0` 的序列和只包含 `1` 的序列均不合法。
- 每次输入都追加到序列末尾，不丢弃任何输入。`check` 反映当前整个序列的合法性。
- 继续输入相同数字会改变最后一段长度的奇偶性，输出应按更新后的段长判定。
- 已经结束的连续段保留在输入历史中，复位之前不能删除或重新划分。
- 两个上升沿之间，`number` 的变化不直接改变输入历史或输出。复位优先于输入接收。
- 输入仅取二值 `0` 或 `1`，不考察 `X`、`Z`；序列长度不设上限。

## T3 键值对序列统计

### 题目描述

使用 Verilog HDL 设计时序电路，每个时钟上升沿接收一个 ASCII 字符，识别字符流中的集合并统计其中合法键值对的数量。

集合以 `{` 开始，以 `}` 结束。集合内的候选项以英文逗号 `,` 分隔，每个合法候选项由一个键、一个英文冒号 `:` 和一个值组成。

键和值须满足以下要求。

1. 键的长度至少为 1，只能包含大小写英文字母 `A-Z`、`a-z` 和数字 `0-9`，且首字符必须为英文字母。
2. 值的长度至少为 1，只能包含数字 `0-9`，允许前导零。值只作字符合法性检查，不要求转换成整数。
3. 候选项首尾以及冒号两侧允许有任意数量的 ASCII 空格 `0x20`。键内部和值内部均不允许出现空格。
4. 每个候选项必须整体满足上述要求，不能只计数其中的合法片段。

输出 `each` 表示当前集合中已经确认合法的键值对数量，输出 `total` 表示所有已经结束的集合中合法键值对数量的最大值。

### 模块接口

模块名为 `sequence_match`

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `rst` | 输入 | 1 | 高电平有效的异步复位信号 |
| `chr` | 输入 | 8 | 本次输入的 ASCII 字符 |
| `each` | 输出 | 8 | 当前集合已确认的合法键值对数量，无符号整数 |
| `total` | 输出 | 8 | 已结束集合的合法键值对数量最大值，无符号整数 |

### 输入范围

- 每个时钟上升沿输入一个字符，没有输入使能或字符流结束信号。
- 集合外可以出现任意普通字符，但不包含 `{`、`}`、`,`、`:`；这些普通字符不参与统计。
- 集合不嵌套，集合内部不会出现额外的 `{`。复位可以发生在集合处理途中。
- 只有 ASCII 空格 `0x20` 可作合法空白字符；其他字符若出现在候选项中，按键和值的规则判定。
- 每个集合中合法键值对的总数不超过 `255`，不考察计数溢出。键和值的长度不另设上限

### 候选项处理要求

- 读到 `{` 后开始新集合，并令 `each=0`。此前的 `total` 保持不变
- 在集合内，读到 `,` 或 `}` 时，结束并判定当前候选项。在遇到结束分隔符之前，该项不计入 `each`
- 合法候选项计数一次，非法候选项不计数。非法项不影响同一集合中其他候选项的判定；在下一个逗号之后重新处理下一项
- 空候选项不计数。允许空集合、集合开头或结尾的逗号，以及连续逗号
- 相同键名可以重复出现，每个独立的合法候选项分别计数

### 时序与复位要求

- `rst=1` 时立即清空识别历史，并令 `each=0`、`total=0`
- `rst=0` 时，在每个时钟上升沿接收一次 `chr`，并在上升沿之后更新状态和输出
- 在集合内读到 `,` 时，若刚结束的候选项合法，则 `each` 加一；否则 `each` 保持不变，`total` 保持不变。
- 在集合内读到 `}` 时，先结算最后一个候选项。设结算后的本集合合法键值对总数为 `C`，则更新 `total` 为原 `total` 与 `C` 中的较大值，同时令 `each=0`，结束当前集合
- 在读入 `}` 的上升沿之后，对外输出为清零后的 `each` 和更新后的 `total`
- 集合尚未结束时不更新 `total`；集合外 `each=0`，普通字符不改变 `total`
- 两个上升沿之间，`chr` 的变化不直接改变识别历史或输出。复位优先于字符接收。
