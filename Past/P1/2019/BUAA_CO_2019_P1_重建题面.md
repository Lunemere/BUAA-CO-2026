# BUAA CO 2019 P1 重建题面

## T1 四位有符号数比较

### 题目描述

使用 Verilog HDL 设计组合逻辑电路，比较两个 4 位有符号数的大小，并输出其中较大的一个。

- `a`、`b` 均为 4 位二进制补码，表示范围为 `-8` 至 `7`。
- `out` 输出数值较大的输入的原始 4 位编码。两数相等时输出该值。
- 不得使用关系运算符 `>`、`<`、`>=`、`<=`。

### 模块接口

模块名为 `compare`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `a` | 输入 | 4 | 第一个有符号数 |
| `b` | 输入 | 4 | 第二个有符号数 |
| `out` | 输出 | 4 | 两数中较大的一个 |

电路没有时钟和复位信号，输出随输入变化。

## T3 幂函数表达式匹配

### 题目描述

使用 Verilog HDL 设计时序电路，逐字符接收 ASCII 字符流，判断从本次复位开始已经接收的整个字符串是否构成一个合法的幂函数项。

合法的幂函数项满足正则表达式：

```text
[+-]?(\d+\*)?x(\^[+-]?\d+)?
```

即依次由以下部分组成：

1. 可选的符号：`+` 或 `-`，至多一个。
2. 可选的系数：一个或多个数字字符 `0` 至 `9`，其后必须紧跟一个 `*`。
3. 必需的小写字母 `x`，恰好一个。
4. 可选的指数：一个 `^`，其后是可选的一个 `+` 或 `-`，再接一个或多个数字字符。

数字串允许以 `0` 开头，只检查字符排列，不计算数值。除上述字符外的任何字符（包括空格）均不合法。

### 模块接口

模块名为 `power`。

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号 |
| `reset` | 输入 | 1 | 高电平有效的异步复位信号 |
| `in` | 输入 | 8 | 当前输入字符的 ASCII 编码 |
| `out` | 输出 | 1 | 已接收的整个字符串是否构成合法幂函数项 |

### 时序与输出要求

- `reset=1` 时立即清空输入历史，`out=0`。复位优先于字符接收。
- `reset=0` 时，在每个时钟上升沿接收一个 `in` 字符。上升沿之后，`out` 表示包含本次字符在内的整个已接收字符串的判断结果。
- 已接收字符串恰好构成合法幂函数项时 `out=1`；仍缺少字符时 `out=0`，例如只收到 `-`、`12`、`3*` 或 `x^-`。
- 合法项后继续输入能延续的字符时按新字符串重新判断，例如 `x` 输出 `1`，接着输入 `^` 输出 `0`，再输入 `2` 输出 `1`。
- 若某次输入使已接收字符串无法通过继续追加字符成为合法项，则进入错误状态。错误状态下始终输出 `0`，后续字符不会重新开始匹配。开始识别新的字符串前必须复位。
