# 2022 CO Pre 题面

## T1：Logisim 串行加数

使用 Logisim 设计一个 Mealy 型时序电路。电路逐次接收一个 2 位编码的正整数，累计其数值。当本次输入使累计值达到或超过 5 时，输出 `1`，并在本次时钟上升沿清空累计值；否则输出 `0`，并保留新的累计值

### 电路接口

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟 |
| `clr` | 输入 | 1 | 清零 |
| `in` | 输入 | 2 | 本次输入的数值编码 |
| `out` | 输出 | 1 | 本次输入是否使累计值达到或超过 5 |

输入编码如下：

| `in` | 数值 |
| --- | --- |
| `00` | 1 |
| `10` | 2 |
| `11` | 3 |

只需处理表中的三种编码，`01` 的行为不作要求。初始累计值为 0。`clr` 为高电平时清零，清零期间 `out=0`，解除清零后从累计值 0 开始处理下一次输入

在 `clr=0` 时，`out` 由当前累计值和当前 `in` 组合决定；每个时钟上升沿采样一次 `in`，按本次结果更新累计值。触发输出 `1` 的输入计入本次判断，清零后不保留其超出阈值的部分。例如，清零后依次输入 `10`、`11`，两次对应的输出依次为 `0`、`1`，第二次时钟上升沿后的累计值为 0

## T2：Verilog 重叠识别序列 101

使用 Verilog HDL 编写 Mealy 型状态机，在逐位输入的二进制序列中识别 `101`。每当最近连续输入的三位构成 `101` 时，输出 `1`；其他情况下输出 `0`。允许重叠识别，例如输入 `10101` 时，应识别到两次 `101`

### 模块接口

模块名为 `recognition`

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟 |
| `reset` | 输入 | 1 | 高电平异步复位 |
| `in` | 输入 | 1 | 当前输入位 |
| `out` | 输出 | 1 | 当前输入位是否完成一次 `101` 匹配 |

`reset=1` 时，立即恢复到尚未匹配任何前缀的初始状态，且 `out=0`。`reset=0` 时，每个时钟上升沿采样一次 `in`；`out` 根据上一次采样后保存的匹配状态和当前 `in` 决定。成功识别后应保留可供后续重叠匹配使用的后缀，不得忽略紧接着到来的输入位

## T3：MIPS 求平方根

编写 MIPS 汇编程序，求一个完全平方数的非负平方根

### 输入格式

输入一个十进制整数 `n`，保证 `1 <= n <= 65536`，且 `n` 为完全平方数

### 输出格式

输出一个十进制整数 `x`，满足 `x * x = n` 且 `x >= 0`。只需输出结果整数，不附加提示文字

程序应使用 MIPS 整数输入、输出系统调用

> 评测机时间要求避免从 1 开始逐个枚举候选平方根的线性查找方式

### 样例

输入：

```text
65536
```

输出：

```text
256
```
