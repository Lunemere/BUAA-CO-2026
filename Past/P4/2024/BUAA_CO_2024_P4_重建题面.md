# BUAA CO 2024 P4

在课下完成的 Verilog 单周期 MIPS CPU 上添加新指令。共两场，每场三题，三题互相独立。

# 第一场

## 第一题

### 指令格式

`EAM`-`rd`-`rs`-`rt`

R型计算类指令，`special` 为`000000`，`funct` 为`101001`

| 31:26 | 25:21 | 20:16 | 15:11 | 10:6 | 5:0 |
| --- | --- | --- | --- | --- | --- |
| `000000` | `rs` | `rt` | `rd` | `00000` | `101001` |

汇编形式：`eam $s1, $s2, $s3`

### 指令描述

取`GPR[rs]`的低16位，视为有符号补码数，对17取模，结果取最小的非负余数（范围0\~16，例如低16位为`0xffff`即-1时结果为16）。若`GPR[rt]`为负数（最高位为1），将该结果一扩展（高16位补1）为32位；否则零扩展为32位。结果存入`rd`。

### RTL语言

```
tmp <- ((signed(GPR[rs][15:0]) mod 17) + 17) mod 17      // 16位，范围0~16
if (GPR[rt][31] == 1)
	GPR[rd] <- {16{1'b1}} || tmp
else
	GPR[rd] <- {16{1'b0}} || tmp
PC <- PC + 4
```

## 第二题

### 指令格式

`CPTL`-`rs`-`rt`-`offset`

I型跳转类指令，机器码为`101100`

| 31:26 | 25:21 | 20:16 | 15:0 |
| --- | --- | --- | --- |
| `101100` | `rs` | `rt` | `offset` |

汇编形式：`cptl $t1, $t2, label`

### 指令描述

无条件按`beq`的方式跳转到`PC+4+sign_ext(offset||00)`。同时：若`GPR[rs]`的低18位二进制表示中存在连续6个1，则将`PC+4`存入`GPR[rt]`；否则将`PC+4`存入`$ra`。

### RTL语言

```
if (GPR[rs][17:0] 中存在连续6个1)
	GPR[rt] <- PC + 4
else
	GPR[31] <- PC + 4
PC <- PC + 4 + sign_ext(offset||00)
```

## 第三题

### 指令格式

`OLW`-`base`-`rt`-`offset`

I型访存类指令，机器码为`110100`

| 31:26 | 25:21 | 20:16 | 15:0 |
| --- | --- | --- | --- |
| `110100` | `base` | `rt` | `offset` |

汇编形式：`olw $t0, 4($t1)`

### 指令描述

从`GPR[base] + sign_ext(offset||00)`处读出一个字。若该字是单调不降的数（二进制表示中某位出现1之后，其更低的各位全为1，即形如`0…01…1`，全0和全1也满足），则将其存入`rt`；否则不写任何寄存器。

### RTL语言

```
vaddr <- GPR[base] + sign_ext(offset||00)
w     <- Memory[vaddr]
if (w 中不存在 i < j 使得 w[i] == 0 且 w[j] == 1)
	GPR[rt] <- w
PC <- PC + 4
```

# 第二场

## 第一题

### 指令格式

`SWMM`-`base`-`rt`-`offset`

I型访存类指令，机器码为`110100`

| 31:26 | 25:21 | 20:16 | 15:0 |
| --- | --- | --- | --- |
| `110100` | `base` | `rt` | `offset` |

汇编形式：`swmm $t0, 4($t1)`

### 指令描述

按`sw`的方式计算地址`addr`。若`GPR[rt]`为偶数，将`GPR[rt]`存入地址`addr[31:2]||00`；否则存入地址`addr[29:0]||00`（即`addr`左移2位，丢弃高2位）。

### RTL语言

```
addr <- GPR[base] + sign_ext(offset)
if (GPR[rt][0] == 0)
	Memory[addr[31:2] || 00] <- GPR[rt]
else
	Memory[addr[29:0] || 00] <- GPR[rt]
PC <- PC + 4
```

## 第二题

### 指令格式

`ES`-`rs`-`rt`-`offset`

I型跳转类指令，机器码为`101100`

| 31:26 | 25:21 | 20:16 | 15:0 |
| --- | --- | --- | --- |
| `101100` | `rs` | `rt` | `offset` |

汇编形式：`es $t1, $t2, label`

### 指令描述

计算`GPR[rs] - GPR[rt]`（有符号）。若不发生溢出，将差存入`rt`，顺序执行；若发生溢出，不写任何寄存器，并按`beq`的方式跳转。

### RTL语言

```
diff <- {GPR[rs][31], GPR[rs]} - {GPR[rt][31], GPR[rt]}
if (diff[32] == diff[31])
	GPR[rt] <- diff[31:0]
	PC <- PC + 4
else
	PC <- PC + 4 + sign_ext(offset||00)
```

## 第三题

### 指令格式

`IBS`-`rd`-`rs`-`rt`

R型计算类指令，`special` 为`000000`，`funct` 为`101001`

| 31:26 | 25:21 | 20:16 | 15:11 | 10:6 | 5:0 |
| --- | --- | --- | --- | --- | --- |
| `000000` | `rs` | `rt` | `rd` | `00000` | `101001` |

汇编形式：`ibs $s1, $s2, $s3`

### 指令描述

判断`GPR[rt]`是否按位对称，即对每个`i`有`GPR[rt][i] == GPR[rt][31-i]`。若对称，将`GPR[rs]`按位取反后存入`rd`；否则将`GPR[rs]`原样存入`rt`。注意两种情况写入的寄存器不同。

### RTL语言

```
if (对任意 0 <= i <= 15 有 GPR[rt][i] == GPR[rt][31-i])
	GPR[rd] <- ~GPR[rs]
else
	GPR[rt] <- GPR[rs]
PC <- PC + 4
```
