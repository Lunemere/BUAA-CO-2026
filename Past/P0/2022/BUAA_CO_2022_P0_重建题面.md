# BUAA CO 2022 P0 重建题面

## T1 五人投票

### 题目描述

使用 Logisim 设计投票表决电路。裁判组由一名组长和四名组员组成，四名组员的编号依次为 `2'b00`、`2'b01`、`2'b10`、`2'b11`。

组长和组员均可以投赞成票、反对票或弃权。组长还可以选择屏蔽一名组员的投票。各投票信号的含义如下。

| 投票者 | `2'b00` | `2'b01` | `2'b10` | `2'b11` |
| --- | --- | --- | --- | --- |
| 组长 | 赞成 | 反对 | 弃权 | 屏蔽指定组员的投票 |
| 组员 | 赞成 | 反对 | 弃权 | 反对 |

当组长选择屏蔽投票时，由 `LI` 指定被屏蔽组员的编号。无论该组员输入何种投票信号，均按弃权处理；组长此次屏蔽操作不计为赞成票或反对票。组长未选择屏蔽投票时，`LI` 不影响表决结果。

统计有效的赞成票和反对票。仅当赞成票数严格大于反对票数时，表决通过；否则不通过。弃权不计入任一类票数，同票时不通过。

### 输入输出

| 名称 | 方向 | 位宽 | 功能 |
| --- | --- | --- | --- |
| `LV` | 输入 | 2 | 组长投票 |
| `LI` | 输入 | 2 | 组长选择屏蔽的组员编号 |
| `T0` | 输入 | 2 | 编号为 `2'b00` 的组员投票 |
| `T1` | 输入 | 2 | 编号为 `2'b01` 的组员投票 |
| `T2` | 输入 | 2 | 编号为 `2'b10` 的组员投票 |
| `T3` | 输入 | 2 | 编号为 `2'b11` 的组员投票 |
| `O` | 输出 | 1 | 表决通过时为 `1`，否则为 `0` |

## T2 文本匹配

### 题目描述

使用 Logisim 设计 Mealy 型状态机，串行接收字符，识别连续出现的字符串 `0121` 和 `1210`。

每个周期输入一个字符，字符编码如下。

| `in` | 含义 |
| --- | --- |
| `2'b00` | 字符 `0` |
| `2'b01` | 字符 `1` |
| `2'b10` | 字符 `2` |
| `2'b11` | 不会出现 |

### 输入输出

| 名称 | 方向 | 位宽 | 功能 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号，在上升沿转移状态 |
| `rst` | 输入 | 1 | 异步复位信号 |
| `in` | 输入 | 2 | 当前周期输入的字符 |
| `out` | 输出 | 2 | 当前周期的匹配结果 |

| 匹配情况 | `out` |
| --- | --- |
| 当前输入使字符串 `0121` 完成匹配 | `2'b01` |
| 当前输入使字符串 `1210` 完成匹配 | `2'b10` |
| 未完成上述任一字符串的匹配 | `2'b00` |

### 时序与匹配要求

- 使用 Mealy 型状态机，输出由当前状态和当前输入共同决定。最后一个字符到来、构成完整匹配时，即在当前周期输出对应结果。
- 在时钟上升沿更新状态，记录本周期输入对后续匹配的影响。
- 匹配允许重叠。完成一次匹配后，已有字符仍可作为下一次匹配的一部分。
- 未命中时输出 `2'b00`，不保持上一次的命中结果。
- 异步复位有效时，无需等待时钟上升沿，清除已有匹配历史，回到尚未接收字符的初始状态。复位解除后重新接收字符，不将初始状态视为已输入的字符。

## T3 斐波那契数列改

### 题目描述

使用 Logisim 设计电路。给定非负整数 $n$，输出数列的第 $n$ 项 $s_n$。数列定义为

$$
s_n =
\begin{cases}
0, & n=0,2, \\
1, & n=1,3, \\
s_{n-1} + (s_{n-2} \oplus s_{n-3}), & n\ge 4\text{ 且 }n\text{ 为偶数}, \\
(s_{n-1} \oplus s_{n-2}) + s_{n-3}, & n\ge 4\text{ 且 }n\text{ 为奇数}.
\end{cases}
$$

其中，$\oplus$ 表示按位异或，$+$ 表示整数加法。

### 输入输出

| 名称 | 方向 | 位宽 | 功能 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟信号，在上升沿更新状态 |
| `rst` | 输入 | 1 | 高电平有效的异步复位信号 |
| `in` | 输入 | 5 | 无符号整数 $n$，取值范围为 $0\le n\le 31$ |
| `out` | 输出 | 32 | 数列项 $s_n$ |

### 时序与复位要求

- `rst = 1` 时，无需等待时钟上升沿，立即将 `out` 清零，并将电路恢复到可开始新一轮计算的初始状态。复位优先于计算。
- 每轮计算前先复位电路，并设置输入 `in`。复位解除后的第一个时钟上升沿为本轮计算的第 1 个周期，此时读取 `in` 作为本轮的目标下标 $n$。
- 从复位解除到读取结果期间，输入 `in` 保持不变，`rst` 保持为 `0`。
- 对所有合法输入，包括 $n=0,1,2,3$，最迟须在本轮第 64 个时钟上升沿后输出正确的 $s_n$。完成计算前，除复位期间外，不检查 `out` 的值。
- 允许提前输出正确结果；计算完成后，`out` 必须保持为 $s_n$，不随后续时钟上升沿继续变化，直到下一次复位。
- 新一轮计算须重新复位。若计算过程中复位，则取消当前计算；复位解除后，按新的输入重新开始。

输入、输出及递推运算均按无符号整数处理。在规定的输入范围内，所有数列项均可用 32 位无符号整数表示。
