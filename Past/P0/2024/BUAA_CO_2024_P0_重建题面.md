# BUAA CO 2024 P0 重建题面

## T1 逆序数对

使用 Logisim 设计组合电路，计算一个四位四进制数的逆序数对个数。四个数码从左到右依次为 `a0`、`a1`、`a2`、`a3`，每个数码的取值范围均为 `0` 至 `3`，可以重复。

### 输入与输出

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `a0` | 输入 | 2 | 最左侧数码 |
| `a1` | 输入 | 2 | 第二个数码 |
| `a2` | 输入 | 2 | 第三个数码 |
| `a3` | 输入 | 2 | 最右侧数码 |
| `count` | 输出 | 3 | 逆序数对总数 |

### 功能要求

对于两个位置 `i < j`，若 `a[i] > a[j]`，则这两个位置构成一个逆序数对。输出所有满足条件的位置对的数量，结果范围为 `0` 至 `6`。

所有数码均按无符号数比较。数值相等的两个数码不构成逆序数对

电路不设置时钟或复位输入，输出由当前四个输入数码决定

## T2 通宵自习室

使用 Logisim 设计时序电路，记录编号为 `0`、`1` 的两个教室的人数。每个时钟周期根据教室选择信号和操作码更新所选教室的人数，并输出两个教室的人数之和。

### 输入与输出

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟，上升沿执行操作 |
| `room` | 输入 | 1 | 教室编号，`0` 选择教室 0，`1` 选择教室 1 |
| `op` | 输入 | 2 | 操作码 |
| `total` | 输出 | 32 | 两个教室人数之和的低 32 位 |

### 操作规则

| `op` | 对所选教室的操作 |
| --- | --- |
| `00` | 保持人数不变 |
| `01` | 人数加一 |
| `10` | 人数减一 |
| `11` | 人数清零 |

两个教室的人数分别以 32 位无符号数保存，加减运算保留低 32 位。人数为 `0` 时减一得到 `0xFFFFFFFF`，人数为 `0xFFFFFFFF` 时加一得到 `0`。

### 初始状态与时序

电路初始时两个教室的人数均为 `0`，`total` 为 `0`。不设置独立的复位输入。

每个时钟上升沿，采样 `room` 和 `op`，仅对所选教室执行一次操作，另一个教室的人数保持不变。`11` 只清空所选教室，不同时清空两个教室。

上升沿更新完成后，`total` 输出更新后的两个人数之和，超过 32 位的进位舍弃。两个上升沿之间改变 `room` 或 `op`，不改变已保存的人数及输出。

## T3 最长严格递增后缀串

使用 Logisim 设计时序电路，每个周期接收一个 4 位无符号数，输出截至当前已接收序列的最长严格递增后缀长度。

### 输入与输出

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟，上升沿采样 |
| `reset` | 输入 | 1 | 高电平有效的同步复位信号 |
| `data` | 输入 | 4 | 本周期输入的无符号数，范围为 `0` 至 `15` |
| `length` | 输出 | 5 | 已接收序列的最长严格递增后缀长度 |

### 后缀与比较规则

设复位后已依次接收的数为 `x1, x2, …, xn`。后缀必须是一段连续的序列，并以最后接收的数 `xn` 结尾。

若后缀中每个数都严格大于紧邻它的前一个数，则该后缀严格递增。`length` 应等于所有符合条件的后缀中最长者所包含的数的个数。

数值按无符号数比较，十六进制 `a` 至 `f` 分别表示数值 `10` 至 `15`。相邻两个数相等时不满足严格递增条件。

非空序列至少具有长度为 `1` 的严格递增后缀。输出仅统计以当前最后一个数结尾的后缀，不保存此前出现过的最大长度。由于输入只有 16 种数值，最长严格递增后缀长度不超过 `16`。

### 初始状态与时序

初始周期表示尚未接收任何数，`length` 为 `0`。

在时钟上升沿，若 `reset = 1`，清空此前接收的序列并将 `length` 置为 `0`，该上升沿的 `data` 不计入序列。复位优先于接收数据；仅改变 `reset` 而未到达上升沿时，输出不立即清零。

在时钟上升沿，若 `reset = 0`，接收当前 `data`，并在状态更新后输出包含本次输入的最长严格递增后缀长度。初始状态或复位后第一次有效接收数据时，`length` 为 `1`。此后每个非复位上升沿均接收一个数。

两个上升沿之间，输出保持不变。
