# BUAA CO 2021 P0 重建题面

## T1 投票表决器

使用 Logisim 设计组合逻辑电路，判断一项议题是否通过。参与投票的共有四人，包括一名组长和三名组员。

### 输入与输出

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `s` | 输入 | 2 | 组长的投票 |
| `t0` | 输入 | 2 | 第一名组员的投票 |
| `t1` | 输入 | 2 | 第二名组员的投票 |
| `t2` | 输入 | 2 | 第三名组员的投票 |
| `res` | 输出 | 1 | `1` 表示通过，`0` 表示否决 |

### 投票编码

| 编码 | 组长 `s` | 组员 `t0`、`t1`、`t2` |
| --- | --- | --- |
| `00` | 同意 | 同意 |
| `01` | 反对 | 反对 |
| `10` | 弃权 | 弃权 |
| `11` | 一票否决 | 反对 |

### 判定规则

组长使用一票否决权时，无论其他人如何投票，均输出 `res = 0`。

组长未使用一票否决权时，统计四人中的同意人数与反对人数，弃权不计入任何一类。仅当同意人数严格大于反对人数时，输出 `res = 1`；否则输出 `res = 0`。

输出由当前输入决定，不设置时钟。

## T2 字符自动机

使用 Logisim 设计 Mealy 型状态机，依次接收字符 `0`、`1`、`2`，识别连续出现的字符串 `2011` 和 `2021`。

### 输入与输出

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟，上升沿更新状态 |
| `reset` | 输入 | 1 | 高电平有效的异步复位信号 |
| `data` | 输入 | 2 | 当前字符的编码 |
| `result` | 输出 | 2 | 当前匹配结果 |

| `data` | 字符 |
| --- | --- |
| `00` | `0` |
| `01` | `1` |
| `10` | `2` |

保证输入不会出现 `11`。

### 识别规则

将此前已经接收的字符与当前输入字符依次连接，若该序列末尾四个字符构成目标字符串，则输出对应编码。

| 末尾四个字符 | `result` |
| --- | --- |
| `2011` | `01` |
| `2021` | `10` |
| 其他情况，包括不足四个字符 | `00` |

状态机连续处理输入流，不要求目标字符串之间存在分隔符。此前匹配失败不影响后续识别；每个字符都可能属于后续目标字符串，不能遗漏连续输入中的任何一次命中。

### 初始状态与时序

初始时尚未接收字符，输出为 `00`。`reset = 1` 时立即清除匹配历史，输出为 `00`；复位期间不接收字符。

`reset = 0` 时，输出由已保存的匹配历史和当前 `data` 共同决定。当前字符使序列匹配成功时，在接收该字符的上升沿到来前即可输出相应编码；上升沿到来时，将当前字符计入历史并更新状态。

每个周期提供一个字符。匹配输出表示当前字符对应的检测结果，不要求在状态更新后再保持一个完整周期。

## T3 递推数列电路

使用 Logisim 设计时序电路，根据输入下标计算数列的指定项。

### 输入与输出

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟，上升沿推进计算 |
| `N` | 输入 | 5 | 无符号下标，范围为 `0` 至 `31` |
| `Nth` | 输出 | 32 | 数列第 `N` 项的值 |

### 数列定义

$$
a_n =
\begin{cases}
0, & n=0,\\
1, & n=1,2,3,\\
a_{n-1} + (a_{n-2}\mathbin{\&}a_{n-3}), & n\ge 4.
\end{cases}
$$

其中，`&` 表示按位与，`+` 表示算术加法。

### 计算与输出要求

每次从电路初始状态开始计算，开始前给定 `N`，并在本次计算及结果保持期间保持 `N` 不变。

电路须在开始后的 64 个时钟周期内完成计算。计算完成之前，`Nth` 保持为 `0`；计算完成后，`Nth` 输出 `a_N`，并在后续时钟周期中保持该结果。

所有合法下标都须正确处理，包括 `N = 0`、`1`、`2`、`3`。
