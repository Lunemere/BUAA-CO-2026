# BUAA 2020 年 P0 重建题面

## T1 校园摆渡车

### 题目描述

校园摆渡车在四个站点之间运行，站点编码如下

| 站点 | 编码 |
| --- | --- |
| 东南 | `00` |
| 合一 | `11` |
| 学二 | `01` |
| 新北 | `10` |

摆渡车有两条运行线路：

- **线路 0**：东南 → 合一 → 学二 → 新北 → 东南
- **线路 1**：学二 → 新北 → 合一 → 学二

请使用 Logisim 设计一个具有同步复位功能的 Mealy 型有限状态机，根据摆渡车当前所在站点和线路选择信号，输出下一站编码

### 输入输出

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `clk` | 输入 | 1 | 时钟，上升沿更新当前位置 |
| `reset` | 输入 | 1 | 同步复位，高电平有效 |
| `line` | 输入 | 1 | 线路选择，0 表示线路 0，1 表示线路 1 |
| `out` | 输出 | 2 | 当前站点在所选线路下的下一站编码，组合输出 |

### 行为要求

- 在时钟上升沿，若 `reset = 1`，当前位置复位为东南站；否则前进到下一站
- 线路选择仅在新北站影响下一站。当前位置为东南站时，无论 `line` 为何值，下一站均为合一站
- `reset` 只控制当前位置的更新，不直接清零输出。复位完成后，`out = 11`
- 测试开始时，先提供至少一个 `reset = 1` 的上升沿完成初始化

## T2 计算分数

使用 Logisim 实现一个组合逻辑电路，根据老师和两名学生给出的分数计算总得分。

### 输入输出

| 信号 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| `tea` | 输入 | 3 | 老师给出的分数 |
| `s1` | 输入 | 2 | 学生 1 给出的分数 |
| `s2` | 输入 | 2 | 学生 2 给出的分数 |
| `total` | 输出 | 4 | 总得分 |

所有分数均为无符号二进制数。

当 `tea = 0` 时，无论 `s1` 和 `s2` 的值是多少，`total = 0`。

当 `tea ≠ 0` 时，`total = tea + s1 + s2`。

该电路不使用时钟，输出随输入变化。

## T3 二进制串处理

使用 Logisim 实现一个组合逻辑电路，将输入的 32 位二进制串转换为规定的 32 位输出串。

### 输入输出

| 数据 | 方向 | 位宽 | 含义 |
| --- | --- | --- | --- |
| 输入串 | 输入 | 32 | 前导零、标记串和待处理串的拼接 |
| 输出串 | 输出 | 32 | 补齐后的待处理串与原长度的拼接 |

### 输入格式

从最高位到最低位，输入串具有以下形式：

`0…0 ‖ 10101 ‖ U`

其中 `‖` 表示二进制串拼接，前导零可以没有；`U` 为待处理的二进制串，长度记为 `n`，不超过 27 位。前导零、5 位标记串和 `U` 的总长度为 32 位。

`U` 的长度由标记串之后剩余的位数确定，包含 `U` 自身的前导零，不能按 `U` 的数值重新计算长度。

### 处理规则

去除前导零和标记串 `10101`，得到 `U`。

- 若 `n = 27`，保持 `U` 不变。
- 若 `n < 27`，在 `U` 的右侧先拼接一个 `1`，再拼接 `26 − n` 个 `0`，得到恰好 27 位的二进制串 `U′`。

将原始长度 `n` 表示为 5 位无符号二进制数，作为输出的最低 5 位；`U′` 作为输出的最高 27 位。

即输出为 `U′ ‖ n[4:0]`，这里的操作是拼接，不是算术加法。长度字段记录补位前的 `U` 的长度。

该电路不使用时钟，输出随输入变化。
