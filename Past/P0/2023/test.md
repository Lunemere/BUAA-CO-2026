# Hexdecimal Match

下列每一行为一个时钟周期：从左至右分别为input, reset, output

a, 0, 00

0, 0, 00

e, 0, 01

这时reset = 1，由于这是异步重置不需要在时间周期里面体现出来

a, 0, 00
