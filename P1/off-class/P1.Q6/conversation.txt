  Declaring a signed register

  Put the signed keyword before the width:

  reg signed [33:0] cnt;

  After that, cnt < 0 does a signed comparison. One trap: if any operand in an
  expression is unsigned, Verilog treats the whole expression as unsigned. cnt <
  0 and cnt + 1 are safe, because plain integer literals are signed. A sized
  literal like 34'd0 is unsigned, so cnt < 34'd0 would be wrong.

  Question 10: Is 32 bits enough?
