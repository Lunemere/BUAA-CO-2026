# JR

**指令格式（R型）**：其机器码编码为 `000000 rs 00000 00000 001000`。

- **opcode (6位)**: `000000`，表示这是R型指令。
- **rs (5位)**: 指定包含目标地址的源寄存器。
- **其他字段**: 均为0。
- **funct (6位)**: `001000`，这是`JR`指令的功能码。
