# 单周期 CPU 设计文档

## 一、整体设计

这次实验用 Verilog 实现了一个 32 位单周期 CPU，顶层模块是 `mips`，输入为 `clk` 和 `reset`。一条指令的取指、译码、运算和读存储器在一个周期内完成，PC、寄存器和数据存储器在时钟上升沿更新。

目前实现了 `add、sub、and、ori、lui、lw、sw、beq、j、jal、jr`，全 0 指令按 `nop` 执行。复位为高电平同步复位，PC 回到 `0x3000`，寄存器和数据存储器清零。没有设置延迟槽，`jal` 保存的返回地址是 `PC+4`。加减法只保留 32 位结果，不处理溢出异常。

## 二、模块划分

我把 CPU 分成了下面 8 个模块，在 `mips.v` 中完成实例化和连线。

| 模块 | 主要功能和实现 |
| --- | --- |
| PC | 保存当前指令地址，上升沿写入 NPC，复位值为 `0x3000`。 |
| NPC | 根据 `NPC_Sel` 和 `zero`，选择顺序地址、分支地址或跳转地址。 |
| IM | 保存指令，共 4096 个 32 位字，通过 `$readmemh` 读取 `code.txt`。索引为 `(Addr-0x3000)>>2`。 |
| Controller | 根据 `OpCode` 和 `Funct` 识别指令，产生写使能、选择信号和运算类型。 |
| GRF | 32 个 32 位寄存器，两个组合读端口、一个同步写端口。禁止写入 0 号寄存器，没有额外的内部转发逻辑。 |
| EXT | 将 16 位立即数扩展到 32 位。`EXTOp=0` 时零扩展，`EXTOp=1` 时符号扩展。 |
| ALU | 完成加、减、按位与、按位或及左移 16 位；另外通过两个操作数相减是否为 0 产生 `zero`。 |
| DM | 共 4096 个 32 位字，组合读、上升沿写，索引为 `Addr>>2`。写入数据来自 GRF 的 `RD2`。 |

IM 和 DM 的容量都是 16 KB，分别对应字节地址范围 `0x3000～0x6FFF` 和 `0x0000～0x3FFF`。

## 三、数据通路

PC 先送入 IM 取指，指令中的 `rs`、`rt` 用来读取寄存器，同时控制器完成译码。ALU 的第一个操作数固定为 `RD1`，第二个操作数由 `ALUSrc` 选择：为 0 时使用 `RD2`，为 1 时使用扩展后的立即数。

不同指令主要区别在于运算方式和写回位置：

| 指令 | 执行过程 |
| --- | --- |
| add、sub、and | 对 `RD1`、`RD2` 运算，将结果写入 `rd`。 |
| ori | 对 `RD1` 和零扩展立即数按位或，结果写入 `rt`。 |
| lui | 立即数先零扩展，再由 ALU 左移 16 位，结果写入 `rt`。 |
| lw | ALU 计算 `RD1+符号扩展立即数`，从 DM 读出数据并写入 `rt`。 |
| sw | 地址计算与 lw 相同，将 `RD2` 写入 DM，不写寄存器。 |
| beq | 比较 `RD1` 和 `RD2`，相等时跳转，不写寄存器和 DM。 |
| j、jal | 跳转到立即数字段指定的地址；jal 还将 `PC+4` 写入 `$31`。 |
| jr | 将 `RD1` 直接作为下一条指令地址。 |
| nop | 不写寄存器和 DM，PC 正常加 4。 |

顶层的写回选择如下，与代码中的信号保持一致：

```verilog
assign RegAddr = (RegDst && Addr2Reg) ? 5'b11111 :
                 RegDst ? rd : rt;
assign WD = Mem2Reg ? Data :
            Addr2Reg ? PC1 + 32'h4 : result;
assign operand2 = ALUSrc ? imm32 : RD2;
```

## 四、控制和跳转

控制器使用组合逻辑，先判断是哪条指令，再生成控制信号。

| 信号 | 位宽 | 取值说明 |
| --- | --- | --- |
| RFWr | 1 | add、sub、and、ori、lui、lw、jal 时为 1。 |
| MemWr | 1 | 只有 sw 时为 1。 |
| ALUSrc | 1 | ori、lui、lw、sw 时为 1，选择立即数。 |
| EXTOp | 1 | lw、sw 时为 1，进行符号扩展，其余为 0。 |
| RegDst | 1 | add、sub、and、jal 时为 1；jal 还需结合 Addr2Reg 选择 `$31`。 |
| Mem2Reg | 1 | 只有 lw 时为 1，选择 DM 读出数据。 |
| Addr2Reg | 1 | 只有 jal 时为 1，选择返回地址写回。 |
| NPC_Sel | 3 | 0：顺序；1：beq；2：j/jal；3：jr。 |
| type | 4 | 指令类型：ori=1、beq=2、lui=3、sw=4、lw=5、sub=6、add=7、j=9、and=10、jal=11、jr=12，其余为 0。 |

NPC 中先计算 `PC4=PC+4`，再按下面的规则选择地址：

- 普通指令或 `beq` 不成立：`NPC=PC4`。
- `beq` 成立：`NPC=PC4+{{14{imm16[15]}},imm16,2'b00}`。
- `j/jal`：`NPC={PC4[31:28],imm26,2'b00}`。
- `jr`：`NPC=RD1`。
