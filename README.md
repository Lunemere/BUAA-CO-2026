# 2026 北航计组实验记录

本仓库记录 2026 年北京航空航天大学计算机组成原理实验课，收录部分往年题目及作者 Lunemere 的解答，并将持续更新 2026 年计组上机题目。

## 仓库结构

目录规划如下，内容会逐步更新：

```text
.
├── Tips/                   # 一些重要的小模块
    └── Initial Value       # Logisim 的 Register初值赋予，后续模块以此类推
├── Pre/                    # 2026 年 Pre
├── P0/                     # 2026 年 P0
├── P1/                     # 2026 年 P1，后续实验以此类推
    └── off-class/          # 课下练习部分
        └── P0_L0_CRC/      # 具体的练习题题面以及对应的解法与感悟
    └── on-class/           # 课上上机部分
└── Past/                   # 往年题目与解答
    └── Pre/
        └── <年份等>/        # 按年份整理
    └── P0/
```

标题中标有“重建版”的内容根据回忆整理，不能保证 100% 准确。

题目与解答仅供参考。如本仓库对你有帮助，欢迎点个 Star。
