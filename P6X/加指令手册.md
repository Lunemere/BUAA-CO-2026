# 考场加一条指令

在 `Controller.v` 找一条最接近的指令。例如加 `andi` 可以参考 `ori`，加 `lb` 可以参考 `lw`。**先在文件上半部写一行 `Is指令名` 识别编码，再在 `always @(*)` 末尾加一个同名的 `else if` 分支。** 复制后改新分支，原指令的分支可以原样保留。

## 1. 读题时确定哪些信号

| 题面给出的信息 | 在代码里写什么 |
| --- | --- |
| 指令格式和固定字段 | `Is指令名` 比较 `OpCode`，R 型同时比较 `Funct`。题面另有固定字段时一并检查 |
| 源寄存器和最早使用它们的阶段 | `A1`、`A2` 默认取 `rs`、`rt`。`TuseRs`、`TuseRt` 默认 `USE_NONE`，读哪个就填写那一路的使用阶段 |
| 运算及输入 | `ALUOp` 选择公式。`ALUSrc=0/1` 分别选择寄存器和扩展后的立即数，`EXTOp=0/1` 分别选择零扩展和符号扩展 |
| 写到哪里、写什么 | `RegAddr` 直接填目的编号，如 `rd`、`rt` 或 `5'd31`。`ResultSel` 选择 ALU、访存或 D 级提前算好的值，`Tnew` 随之产生 |
| 额外动作 | 存储指令设置 `MemWr` 和 `MemSize`，跳转指令设置 `NPC_Sel`，条件分支再填 `CmpOp` |

每次译码先采用 `always` 开头的默认值，随后执行匹配的指令分支。默认顺序取指、`RegAddr=0`、`MemWr=0`。全零 `nop` 走这条默认路径。

### 选择信号还有哪些空号

下表是正式 RTL 中的十进制编号。已有指令共用同一种运算或数据来源时，直接复用已有编号。例如 `bne` 和 `beq` 的目标地址公式相同，两者都选 `NPC_BRANCH`，只需区分 `CmpOp`。

| 信号 | 位宽 | 已用编号 | 空闲编号 | 新增一种行为时改哪里 |
| --- | --- | --- | --- | --- |
| `NPC_Sel` | 3 | 0～3 | **4～7** | `NPC.v` 的 `case (NPC_Sel)` 选择目标地址 |
| `SlotMode` | 3 | 0～3 | **4～7** | `mips.v` 的 `D_ClearSlot` 决定是否清空延迟槽 |
| `CmpOp` | 4 | 0～6 | 7～15 | `NPC.v` 的 `case (CmpOp)` 判断是否跳转 |
| `ALUOp` | 5 | 0～10 | 11～31 | `ALU.v` 的 `case (ALUOp)` 计算结果 |
| `ASel` | 3 | 0～3 | 4～7 | `mips.v` 的 `E_Operand1` 选择 ALU 第一输入 |
| `ALUSrc` | 1 | 0～1 | 无 | `mips.v` 的 `E_Operand2` 选择 ALU 第二输入 |
| `EXTOp` | 1 | 0～1 | 无 | `EXT.v` 的 `imm32` 决定立即数扩展方式 |
| `ResultSel` | 3 | 0～2 | 3～7 | `Controller.v` 的 `Tnew`，以及 `mips.v` 中对应级的结果选择与转发 |
| `MemSize` | 3 | 0～2 | 3～7 | `DM.v` 的 `case (MemSize)` 选择读出数据和写入字 |

选择信号端口和流水寄存器直接写明位宽，例如 `NPC_Sel` 为 `[2:0]`，`MemSize` 为 `[2:0]`。增加选择编号时只扩展对应信号的位宽并新增编码，不给位宽另设宏。`ALUSrc` 和 `EXTOp` 各只有两种取值，保持单比特控制。

`Tuse` 填源操作数的使用级，`Tnew` 填结果还要等几拍，`FWD_*` 对应已有的转发来源。普通新指令按第 7 节选择时序即可。

## 2. 添加 `andi rt, rs, imm16`

`andi` 要把 `rs` 与零扩展的立即数按位与，把结果写入 `rt`。ALU 已有 `ALU_AND`，这道题只改 `Controller.v`。

第一处，把下面一行放在 `wire IsOri` 附近。`OpCode` 是 `Instr[31:26]`，可以把题面的六个固定比特直接抄下来。`andi` 的低六位属于立即数，可以取任意值。

```verilog
wire IsAndi = (OpCode == 6'b001100);
```

第二处，在 `IsJal` 分支的 `end` 和整个 `always` 的 `end` 之间接上这个分支。

```verilog
else if (IsAndi) begin
    TuseRs = `USE_E;
    ALUOp = `ALU_AND;
    ALUSrc = 1'b1;
    EXTOp = 1'b0;
    RegAddr = rt;
    ResultSel = `RESULT_ALU;
end
```

`rt` 在这条指令里只作为目的寄存器，`TuseRt` 取默认的 `USE_NONE`。例如前一条 `lw` 恰好也写这个 `rt`，两条指令之间没有读取这个值的相关性。

## 3. 常见指令可以参考哪一段

下表中的指令用于扩展练习。正式译码支持指导书的十条指令以及原工程的 `and`、`j`。每次按题面选一条，在自己的新分支里填写对应取值。

### 算术、逻辑与移位

| 新指令 | 匹配的编码（二进制） | 参考分支 | 新分支要填的区别 |
| --- | --- | --- | --- |
| `xori` | OpCode `001110` | `IsOri` | `ALUOp = ALU_XOR`，立即数零扩展 |
| `addiu` | OpCode `001001` | `IsOri` | `ALUOp = ALU_ADD`，`EXTOp = 1'b1` |
| `or`、`xor`、`nor` | OpCode `000000`，Funct 依次为 `100101`、`100110`、`100111` | `IsAdd` | ALU 运算依次为 `ALU_OR`、`ALU_XOR`、`ALU_NOR` |
| `slt`、`sltu` | OpCode `000000`，Funct 依次为 `101010`、`101011` | `IsAdd` | `ALU_SLT` 做有符号比较，`ALU_SLTU` 做无符号比较 |

例如 `sll rd, rt, shamt` 的高六位和低六位都是 `000000`。源数据取 `rt`，移位量取自 `Instr[10:6]`。

```verilog
// 放在指令识别区
wire IsSll = (OpCode == 6'b000000) && (Funct == 6'b000000);

// 接在 always 中已有的指令分支后
else if (IsSll) begin
    TuseRt = `USE_E;
    ASel = `A_SHAMT;
    ALUOp = `ALU_SLL;
    RegAddr = rd;
    ResultSel = `RESULT_ALU;
end
```

`A_SHAMT` 把移位量送到 ALU 的第一个输入，第二个输入默认取 `rt`。全零指令在这项扩展中写 `$0`，仍可用作 `nop`。`srl` 和 `sra` 的 Funct 分别是 `000010`、`000011`，对应运算是 `ALU_SRL`、`ALU_SRA`。

### 字节与半字访存

| 新指令 | OpCode | 参考分支 | MemSize | LoadUnsigned |
| --- | --- | --- | --- | --- |
| `lb`、`lbu` | `100000`、`100100` | `IsLw` | `MEM_BYTE` | `lb` 填 0，`lbu` 填 1 |
| `lh`、`lhu` | `100001`、`100101` | `IsLw` | `MEM_HALF` | `lh` 填 0，`lhu` 填 1 |
| `sb`、`sh` | `101000`、`101001` | `IsSw` | `MEM_BYTE`、`MEM_HALF` | 用默认值 |

`LoadUnsigned` 控制从 DM 读出的字节或半字怎样扩展。算地址时这六条指令都用 `rs + signext(offset)`，所以各自分支都将 `EXTOp` 设为 `1'b1`。DM 已有小端字节选择和局部写入，半字访问须对齐。`sb`、`sh` 的仿真日志记录对齐字地址及局部写入后的整字。

### 分支与寄存器链接

`bne` 的 OpCode 是 `000101`。复制 `IsBeq` 的控制分支，把新分支的 `CmpOp` 设为 `CMP_NE`，两路寄存器都在 D 级参与比较。

`jalr rd, rs` 从 `rs` 取跳转目标，向 `rd` 写返回地址。两项动作可以直接写在同一分支中。

```verilog
wire IsJalr = (OpCode == 6'b000000) && (Funct == 6'b001001);

// always 中
else if (IsJalr) begin
    TuseRs = `USE_D;
    NPC_Sel = `NPC_REG;
    RegAddr = rd;
    ResultSel = `RESULT_EARLY;
    EarlyData = PC + 32'd8;
end
```

如果题面要求“`rs > 0` 才分支并写 `$31`”，新分支里的控制信号如下。识别行按题面填写，REGIMM 类编码还要匹配 `rt` 中的固定值。

```verilog
else if (IsBposlink) begin
    TuseRs = `USE_D;
    CmpOp = `CMP_GTZ;
    NPC_Sel = `NPC_BRANCH;
    RegAddr = 5'd31;
    ResultSel = `RESULT_EARLY;
    EarlyData = PC + 32'd8;
    LinkOnlyTaken = 1'b1;
end
```

`LinkOnlyTaken` 使顶层在条件失败时将进入 E 级的目的编号清零。题面要求无论是否跳转都链接时，取默认值 0。`NPC` 还支持 `CMP_LTZ`、`CMP_LEZ`、`CMP_GEZ` 和 `CMP_ALWAYS`。

### 清空延迟槽

在新指令自己的 `Controller.v` 译码分支中设置 `SlotMode`。条件取自 `NPC.v` 用转发后的操作数算出的 `D_Taken`。

| 题面要求 | 新分支中的赋值 |
| --- | --- |
| 始终执行延迟槽 | 采用默认值 `SLOT_KEEP` |
| 条件失败时清空，如 BONALL | ``SlotMode = `SLOT_CLEAR_IF_FALSE;`` |
| 条件成立时清空 | ``SlotMode = `SLOT_CLEAR_IF_TRUE;`` |
| 总是清空，如 JTL | ``SlotMode = `SLOT_CLEAR_ALWAYS;`` |

例如 BONALL 还要按题面补上“互为相反数”的比较，并无条件把 `PC+8` 写入 `$31`，所以 `LinkOnlyTaken` 取默认值 0。比较失败时，分支本身仍进入 E 并完成链接，同一拍 F 中的延迟槽作废，PC 前进到分支地址加 8。

若分支紧跟一条提供比较操作数的 `lw`，把相应源的使用时间填为 `USE_D`。阻塞期间 PC 和 D 保持，等值转发到 D 且阻塞解除的那个上升沿，F→D 才按 `SlotMode` 接收指令或插入气泡。

### 用第 5 个 NPC 编号加一种跳转目标

以练习指令 `jradd rs, rt` 为例。它执行一条延迟槽指令，然后跳到两个寄存器值之和。假定目标字对齐，练习编码为 `000000 rs rt 00000 00000 111100`。

在 `Defines.vh` 的 `NPC_REG` 后面增加目标选择编号。

```verilog
`define NPC_RS_RT 3'd4
```

在 `Controller.v` 的识别区和译码分支分别加入以下两段。两个源值都在 D 级计算目标，因此都填 `USE_D`。

```verilog
wire IsJradd = (OpCode == 6'b000000) && (Funct == 6'b111100) && (Instr[15:6] == 10'd0);

// always 中
else if (IsJradd) begin
    TuseRs = `USE_D;
    TuseRt = `USE_D;
    NPC_Sel = `NPC_RS_RT;
end
```

在 `NPC.v` 的 `case (NPC_Sel)` 中、`default` 之前增加一行。这里的 `Rs`、`Rt` 已经过 D 级转发。

```verilog
`NPC_RS_RT: NextPC = Rs + Rt;
```

例如前一条 `ori` 刚写 `rt`，`jradd` 会停一拍，等该值进入 M 级后再计算目标。延迟槽照常执行。这个例子只改上述三个文件。

## 4. 添加新的运算公式

假设练习指令为 `rol rd, rs, rt`，把 rs 循环左移 `rt[4:0]` 位。本例自选 `opcode=0, funct=3f`，不是课程规定的新指令编码。

第一处，在 `Defines.vh` 的 `endif` **之前**增加运算编号：

```verilog
`define ALU_ROL 5'd16
```

第二处，在 `Controller.v` 添加这条指令的识别行和控制分支。

```verilog
wire IsRol = (OpCode == 6'b000000) && (Funct == 6'b111111);

// always 中
else if (IsRol) begin
    TuseRs = `USE_E;
    TuseRt = `USE_E;
    ALUOp = `ALU_ROL;
    RegAddr = rd;
    ResultSel = `RESULT_ALU;
end
```

第三处，在 ALU 的 case 中添加：

```verilog
`ALU_ROL: result = (operand1 << operand2[4:0]) |
                   (operand1 >> ((32 - operand2[4:0]) & 31));
```

不需要更改 `mips.v` 或 `Hazard.v`。ALU 结果进入 M 寄存器后就能转发，随后到 W 写回。

ALU 已传入 **E 级完整指令 `Instr`**。如果新算法还需要立即数、shamt 或特殊字段，直接取 `Instr[...]`。当两个寄存器都参与计算时，保持 `ALUSrc = 1'b0`；特殊立即数字段可以从 `Instr` 单独读取，避免用立即数覆盖第二个寄存器输入。

本例选 16，写成 `5'd16`。写成 `4'd16` 会截断成 0，与 `ALU_ADD` 重号。

## 5. 条件写回

例如 `movz rd, rs, rt`，仅当 rt 为零才把 rs 写入 rd。

```verilog
// Defines.vh
`define ALU_MOVZ 5'd12

// Controller.v 的指令识别区
wire IsMovz = (OpCode == 6'b000000) && (Funct == 6'b001010);

// Controller.v 的 always 中
else if (IsMovz) begin
    TuseRs = `USE_E;
    TuseRt = `USE_E;
    ALUOp = `ALU_MOVZ;
    RegAddr = rd;
    ResultSel = `RESULT_ALU;
end

// ALU，case 分支
`ALU_MOVZ: begin
    result = operand1;
    WriteOK = (operand2 == 0);
end
```

顶层已经接好 `WriteOK`。条件失败时，M 级的实际目的寄存器变为 0，从而同时取消后续转发和写回。不要只在 GRF 的写使能上增加条件，否则后面的指令可能收到本不该写出的值。

`rt` 在 E 级参与条件判断，所以 `IsMovz` 要填 `TuseRt = USE_E`。`WriteOK` 适用于 E 级决定是否写寄存器的计算／访存指令；不要用它去撤销已在 E 级向前转发的 `RESULT_EARLY` 值，也不要把它误当成存储写使能。

## 6. 改目的寄存器或改地址公式

假设一条 R 型指令把 rs+rt 写回 rs：

```verilog
else if (IsSumrs) begin
    TuseRs = `USE_E;
    TuseRt = `USE_E;
    ALUOp = `ALU_ADD;
    RegAddr = rs;
    ResultSel = `RESULT_ALU;
end
```

假设一条 R 型指令读取 `Memory[GRF[rs]+GRF[rt]]` 并写入 rd：

```verilog
else if (IsLwrr) begin
    TuseRs = `USE_E;
    TuseRt = `USE_E;
    ALUOp = `ALU_ADD;
    ALUSrc = 1'b0; // 两路寄存器参与地址计算
    MemSize = `MEM_WORD;
    RegAddr = rd;
    ResultSel = `RESULT_MEM;
end
```

这两种情况都不需要改 Hazard。测试脚本在临时副本中分别使用 funct `3e`、`3d` 验证了这两种接法。

## 7. Tuse 只记“最早使用”

| 源操作数用途 | 应填写的 Tuse |
| --- | --- |
| D 级判断分支、计算寄存器跳转目标 | `USE_D`，值为 0 |
| E 级计算、算地址、判断 E 级条件 | `USE_E`，值为 1 |
| M 级才使用，例如普通 sw 的写入数据 | `USE_M`，值为 2 |
| 完全不读取这个寄存器 | `USE_NONE`，值为 3 |

同一个寄存器被使用多次，填写最早的一次。例如“只有 rt 大于零才执行存储”，如果你在 E 级检查 rt，就要在新指令自己的分支里填 `TuseRt = USE_E`，即使数据最终仍在 M 级写入。

结果时间由 `ResultSel` 统一确定：

| ResultSel | 数据存放位置 | 进入 E 时的 Tnew | 进入 M 时的 Tnew |
| --- | --- | --- | --- |
| `RESULT_EARLY` | D 级算好，进入 E_EarlyData | 0 | 0 |
| `RESULT_ALU` | E 级计算，进入 M_Result | 1 | 0 |
| `RESULT_MEM` | M 级访存，进入 W_Result | 2 | 1 |

如果新指令只是换了计算公式，可以复用对应阶段的 `RESULT_*`。如果新增了 `ResultSel` 编号，要在 `Controller.v` 的 `Tnew` 表达式中明确该结果的就绪时间，并检查 `E_EarlyData`、`M_Result` 或 `W_Result` 能在该拍提供正确的值。

`Tnew=0` 的含义是结果已经位于流水寄存器中，不能为了少停一拍而提前把 load 的 Tnew 改成 0。

## 8. 特殊题仍然可能需要改数据通路

当前数据通路支持两路通用寄存器输入、至多一次通用寄存器写回、D 级分支、E 级计算和 M 级单次访存。

- **读内存后再加工数据**：在 M 到 W 的数据选择前加组合处理，使用 `M_MemData`、`M_Rs`、`M_Rt`、`M_Instr`。结果仍应在 W 才可转发，保持 `RESULT_MEM` 的时间属性。
- **额外的 M 级源操作数**：M 级已保留两个源值、源编号及 W→M 转发；但仍须正确填写 D 级的最早使用时间。地址计算先用 rs，就仍是 `USE_E`。
- **新的分支条件**：在 `Defines.vh` 加比较编号，在 NPC 的 case 加条件，再在新指令分支里设置 `NPC_Sel`、`CmpOp` 和参与比较的源操作数时间。`NPC` 的 `Instr` 已是 D 级指令，Rs/Rt 已转发。
- **新的跳转目标公式**：需要修改 NPC 的目标选择，并保留当前题目规定的延迟槽行为。
- **根据运行结果决定目的寄存器、一次写两个寄存器、读取第三个寄存器、多周期运算、M 级才决定跳转**：超出了现有 A/T 模型或控制流前提，需要针对题意增加通路和控制。

新增控制信号时，要在 Controller 输出、mips 声明与实例化、必要的流水寄存器赋值及复位／气泡赋值中一起接齐。普通指令优先复用已经存在的选择信号。

## 9. 加完怎样验证

先检查基础功能是否被影响：

```bash
python3 tests/run.py --no-extensions
```

然后给新指令至少安排以下相邻关系，源值尽量选成转发前后不同：

1. 前一条 ALU 指令生成它的 rs，再分别生成它的 rt。
2. 前一条 lw 生成它的源值；分别插入 0、1、2 个 nop。
3. 新指令的结果紧接着被 add、beq、sw 使用。
4. 两条前驱连续写同一个寄存器，检查是否使用较新的值。
5. 条件成立和不成立、目的为 `$0`、立即数与数据的边界值。
6. 若是分支，检查跳转／不跳转以及延迟槽中的写寄存器或存储操作。

参考模型在 `tests/run.py` 的 `reference()` 中按指令语义执行，不读取 RTL 的控制信号。增加自定义测试时，要把新语义加入模型，再增加 Program 的编码和用例。用当前题目的汇编程序与开启延迟槽的 MARS 对拍也是可选方式；本次验证没有调用 MARS。

不带参数运行 `python3 tests/run.py` 还会在临时副本里自动练习上述扩展。它不会把示例指令写进正式 CPU。你已经改了自己的考试指令时，建议使用 `--no-extensions`，避免示例编码或运算编号与你的指令冲突。
